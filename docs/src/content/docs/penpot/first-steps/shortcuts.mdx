Penpot 提供快捷键来帮助你加快工作流。许多键盘快捷键会显示在菜单中的命令名称旁边。

这里列出了可在 Penpot 中使用的所有键盘快捷键。请注意，大多数快捷键位于工作区，因为那里最常用。

您也可以在 GitHub 文件中查看最新的快捷键列表。

## 工作区

工作区是实际创建设计的地方。

### 图层面板

图层侧边栏的键盘快捷键和鼠标操作。面板中的图层顺序是从下到上；`Tab` 和 `Shift` + `Tab` 用于在当前选中项的同级图层之间移动（到达末尾时会循环）。使用 `Ctrl` + `↑` / `↓` 可更改列表中的堆叠顺序（参见修改图层）。

| 操作 | Linux 和 Windows | macOS |
| --- | --- | --- |
| 选择下一个图层（同级） | `Tab` | `Tab` |
| 选择上一个图层（同级） | `Shift` `Tab` | `⇧` `Tab` |
| 选择父图层 | `Shift` `Enter` | `⇧` `Enter` |
| 选择子级（组、画板或布尔；单选） | `Enter` | `Enter` |
| 重命名下一个图层（面板重命名时） | `Tab` | `Tab` |
| 重命名上一个图层（面板重命名时） | `Shift` `Tab` | `⇧` `Tab` |
| 展开或折叠 | 点击展开箭头 | 点击展开箭头 |
| 展开整个子树 | `Alt` + 点击展开箭头 | `⌥` + 点击展开箭头 |
| 折叠侧边栏中的全部图层 | `Shift` + 点击展开箭头 | `⇧` + 点击展开箭头 |
| 添加图层到选择 | `Ctrl` + 点击图层 | `⌘` + 点击图层 |
| 范围选择图层 | `Shift` + 点击图层 | `⇧` + 点击图层 |
| 缩放到图层 | 双击图层图标 | 双击图层图标 |
