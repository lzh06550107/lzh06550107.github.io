你可以直接在浏览器中开始使用 Penpot，或者将它安装在你自己的服务器上。

## 在你的浏览器中

要在线使用 Penpot，请在浏览器中访问 [design.penpot.app](https://design.penpot.app/?_gl=1*p4hdbd*_gcl_au*NDAxODIyNzEzLjE3ODE2NzkzNzQ.*_ga*MTUzMTY5MTQ2Ni4xNzgxNjc5Mzc0*_ga_K0KF97C51Q*czE3ODE5NjAwMjckbzE1JGcxJHQxNzgxOTYwMDMyJGo1NSRsMCRoMA..) 并开始设计。为了获得最佳体验，请使用最新版本的 Google Chrome 或 Mozilla Firefox。我们也为 WebKit（Safari / Epiphany）提供特定支持。

如果你想阅读更多关于 Penpot 及其新版本的信息，也可以访问 [penpot.app](https://penpot.app/)。在那里，点击 “注册” 按钮。系统会要求你创建一个账号。我们只需要一个邮箱。也有一些可用的身份验证提供商。

## 在你自己的服务器上

目前，私有 Penpot 实例只需要基本的 Docker 知识。

你可以按照 [技术指南](https://help.penpot.app/technical-guide/getting-started) 中的说明运行自己的 Penpot 服务器。
