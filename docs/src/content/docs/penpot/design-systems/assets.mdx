资产库允许你存储元素和样式，以便轻松复用。学习创建和管理资产库，可以更好地组织设计中的组成部分并加速工作流。

## 资产类型

在 Penpot 中可以存储不同类型的资产：

- 组件：组件是可以跨文件多次复用的图层或图层组。
- 颜色：创建颜色样式，并用于填充和描边。
- 排版：Penpot 允许你保存一组可复用属性组成的排版样式。你也可以取消链接排版样式，同时保留文本图层属性。
- [已弃用] 图形：在 Penpot 2.0 之前的版本中，位图和矢量图片可存储在 Graphics 区域。该类型已弃用，改由组件替代。

## 添加资产到库

可以使用 “+” 图标添加资产。每个类别都有自己的添加动作。

### 组件

有两种方式把组件添加到资产库：

1. 主组件在创建时会自动存储到本地库中。可以在组件章节了解更多关于组件的内容。
2. 点击 “+” 启动导入图片，该图片会作为组件添加。

(视频略)

### 颜色

点击 “+” 会打开取色器，并把颜色添加到库中。可以了解更多关于管理颜色的内容。

(视频略)

库中的半透明颜色会在资产名称中显示其不透明度百分比。

### 排版

从文本属性（右侧边栏）创建的所有排版样式都会自动存储到库中。你也可以点击 “+” 从头创建新的排版样式。

每个排版组都有自己的添加按钮，可直接在该组中创建样式。编辑排版样式时，请使用排版对话框中的删除和复制按钮。

(视频略)

提示：如果选择具有某些属性（字体族、字号、行高等）的文本图层，并点击资产库（左侧边栏）Typographies 区域中的 “+”，创建的排版样式会包含该文本图层的属性。

## 编辑资产

左键点击库中的任何资产可显示选项菜单。某些选项仅适用于特定资产。

- 组件：重命名、复制、删除、分组。
- 颜色：重命名、编辑、复制、删除。
- 排版：重命名、编辑、复制、删除。

(视频略)

## 使用资产

- 组件：直接从库中把组件拖到视口。
- 颜色：选中形状或文本后，点击库中的颜色可将其作为填充应用。如果点击时按住 `Alt`（macOS 为 `⌥`），颜色会应用到描边。
- 排版：选中文本图层后，点击库中的排版样式即可应用。

(视频略)

## 组织资产

了解如何更好地查看和组织你的资产：

### 资产列表视图

可以在列表视图和网格视图之间切换。

- 网格视图：显示缩略图，更容易直观看出特定资产内容，尤其是组件。
- 列表视图：更适合通过名称识别资产，并同时查看更多资产。

(视频略)

### 排序资产

点击排序按钮可更改字母顺序。

(视频略)

### 搜索资产

使用 Search assets 框，可按输入内容筛选名称匹配的资产。

(视频略)

### 筛选资产

你可以决定显示所有资产类型，或只显示选定类型（组件、颜色或排版）。

### 多选资产

可在资产库中选择多个资产，以便批量操作。

(视频略)

### 分组资产

创建库分组有两种方式：

1. 使用斜杠 `/`：选择一个资产并按 `FOLDER NAME/ASSET NAME` 格式重命名，例如 `Buttons/Alert Button`。
2. 使用 “Group” 选项：在库中选择一个或多个资产，右键显示菜单，然后选择 “Group”。

(视频略)

### 取消资产分组

可以通过菜单选项（此时为 “Ungroup”）或重命名，以与分组相同的方式取消资产分组。

### 删除组

Delete group 会从库中移除该组内的所有资产。Penpot 会要求确认将删除多少资产。此选项可在组件、颜色和排版组的上下文菜单中使用。

### 拖动资产到组

在库之间移动资产最直接的方式之一，就是拖动资产到目标组。
