# 导出和导入 Penpot 文件

你可以把 Penpot 文件导出到电脑，也可以从电脑把文件导入到项目中。

## 导出 Penpot 文件

导出文件在很多情况下都很有用。有时你想为文件创建备份；有时你想把 Penpot 文件分享给不属于你团队的用户；也可能想在 Penpot 之外备份文件，不论你使用的是 SaaS 版本还是自托管实例。

### 如何导出 Penpot 文件

#### 导出单个文件

你可以从工作区或仪表盘下载（导出）文件。

从仪表盘：在文件卡片菜单中选择下载选项。

![](/images/penpot/export-1.png)

从工作区：在主菜单中选择下载选项。

![](/images/penpot/export-2.png)

#### 导出多个文件

选择多个文件即可同时导出。一个覆盖层会显示不同导出的进度。

(视频略)

#### 导出链接到共享库的文件

导出链接到共享库的文件时，可以用不同方式导出它们的资产。选择最适合你的方式。

- **Export shared libraries**：带有共享库的文件会包含在导出中，并保持链接关系。
- **Include shared library assets in file libraries**：文件会导出，并把所有外部资产合并到文件库中。
- **Treat shared library assets as basic layers**：共享库不会包含在导出中，也不会向库中添加资产。

![](/images/penpot/export-3.png)

## 导入 Penpot 文件

当前文件导入大小上限为 1GB。

导入选项位于项目菜单中。点击 **Import files**，然后选择一个或多个 `.penpot` 文件导入。你也可以导入 `.zip` 文件。

![](/images/penpot/export-4.png)

在把文件导入到项目之前，你仍有机会查看要导入的项目，了解哪些项目无法导入，并可以丢弃文件。

![](/images/penpot/export-5.png)

## Penpot 文件格式

Penpot 会导出为一种独特格式，通过更高效、更具互操作性的方式简化文件和资产的导入导出。

不同于其他设计工具，Penpot 的格式建立在标准语言之上。导出的文件本质上是一个 ZIP 归档，其中包含二进制资产（如位图和矢量图像），以及可读的 JSON 结构。通过避免专有格式，Penpot 让用户摆脱特定工具的限制，同时支持顺畅的第三方集成。

### 已弃用的 Penpot 文件格式

这些格式只能从 2.3 或更早版本导出，但可以导入到任意 Penpot 版本。

可以导入/导出 Penpot 文件的已弃用格式有两种：一种是标准格式，一种是二进制格式。对于任何文件，你始终都有机会使用两者。

#### [已弃用] Penpot 文件（.penpot）

快速格式。Penpot 专用二进制格式。

- ✅ 在导出和导入时，内存和传输时间效率很高。
- ❌ 只能在 Penpot 中打开。
- ❌ 不透明，代码难以探索。

#### [已弃用] 标准文件（.zip）

开放格式。一个包含 SVG 和 JSON 的压缩文件。

- ✅ 允许文件被其他软件打开（不过，在这些场景中导出为 SVG 似乎是常见做法）。
- ✅ 支持一些自动化和集成。
- ✅ 是透明、现有、开放的标准格式。
- ❌ 在导出和导入时，内存和传输时间效率很低（这是因为 SVG）。
