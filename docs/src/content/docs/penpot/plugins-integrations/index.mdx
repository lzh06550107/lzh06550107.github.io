## 插件

插件是扩展 Penpot 功能的完美工具。你可以安装可用的插件，或者创建一个符合你需求的插件！

### 如何安装插件

#### 从 PenpotHub 安装

你可以在 [Penpot Hub](https://penpot.app/penpothub/plugins) 找到可用的插件，并在 Plugins 页面中点击所需插件旁边的 **Install**，直接安装插件。

![](/images/penpot/plugins-1.png)

#### 使用 URL

另一种安装插件的方式是复制插件作者提供的 URL（带有 `.json` 扩展名），并将其粘贴到 Plugin Manager 中。

![](/images/penpot/plugins-2.png)

:::caution
请注意，你需要授予对你的文件的访问权限。插件可能由外部方创建，因此在授予访问权限之前，请确保你信任它。你的数据隐私和安全对我们很重要。如果你有任何疑虑，请联系 [support](mailto:support@penpot.app)。
:::

:::note
如果插件之后由作者更新，并且需要新的权限，我们会通知你，以便你可以更新它。
:::

![](/images/penpot/plugins-3.png)

插件安装完成后，只要你有权限访问它，就可以在你任意团队中的文件里访问它。如果你团队中的其他成员想要使用该插件，他们需要单独安装它。

### Plugin Manager

要开始使用插件，你首先需要打开 Plugin Manager。在工作区中，有几种不同的方式可以访问 Plugin Manager：

- 从工具栏；
- 从菜单；
- 使用快捷键 **Ctrl + Alt + P**。

#### 工具栏

![](/images/penpot/plugins-4.png)

#### 菜单

![](/images/penpot/plugins-5.png)

### 使用插件

要使用插件，请前往 Plugin Manager，并点击所需插件旁边的 **Open**，就是这样，尽情使用吧！

![](/images/penpot/plugins-6.png)

### 创建插件

你可以从零开始创建自己的插件，也可以使用模板开始。你可以在[技术指南](https://help.penpot.app/plugins/create-a-plugin/)中找到创建插件的完整指南。

## Webhooks

Webhooks 允许其他网站和应用在 Penpot 中发生特定事件时收到通知，从而确保能够与其他服务创建集成。虽然我们仍在开发插件系统，但这是与其他服务创建集成的一种聪明而简单的方式。

![](/images/penpot/plugins-7.png)

你可以在[技术指南](/technical-guide/integration/#webhooks)中找到关于 Penpot webhooks 的详细信息。
