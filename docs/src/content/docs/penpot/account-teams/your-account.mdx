# 你的账户

你的账户设置可以在用户区域的 **Your account** 中修改。在这里，你可以更改个人资料、密码或账户语言，也可以生成个人访问令牌并访问发行说明
### 个人资料

如果你想更改账户关联的电子邮件地址，或完全删除账户，可以在 **Profile** 区域完成
### 密码

如果你想把密码改为新密码，可以在 **Password** 区域完成
### 通知

?**Notifications** 区域，你可以配置电子邮件通知和仪表盘通知
### 设置

?**Settings** 区域，你可以更改语言和界面颜色主题
### UI 主题

Penpot 的默认界面是深色，但你可以随时切换到浅色选项。更改主题有两种方式
- ?**Your account** > **Settings** 更改?- 使用快捷?`Alt/⌥` + `M`?
### 访问令牌

?**Access tokens** 区域，你可以管理访问令牌
