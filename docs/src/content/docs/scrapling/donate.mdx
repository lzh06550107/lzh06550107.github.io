如果你想支持 Scrapling 以及作者持续维护这些项目：我一直利用自己的业余时间开发它们，并投入了相当多的资源与精力，免费提供给社区。成为赞助者，等于直接补充我的咖啡储备、帮助我承担日常责任，也让我能持续更新现有项目，甚至创造新的项目。

你可以直接通过 [GitHub Sponsors](https://github.com/sponsors/D4Vinci) 或 [Buy Me a Coffee](https://buymeacoffee.com/d4vinci) 赞助我。

谢谢你，保持好奇，继续探索这个世界！❤️

## 广告

如果你希望向我们的目标受众**推广**你的业务，可以查看[可用赞助档位](https://github.com/sponsors/D4Vinci)：

### 1. [Silver 档位](https://github.com/sponsors/D4Vinci/sponsorships?tier_id=435495)（$100/月）

权益：

1. 你的 Logo 将展示在 [Scrapling 项目页顶部](https://github.com/D4Vinci/Scrapling?tab=readme-ov-file#sponsors)。
2. 同一个 Logo 也会以相同方式展示在 [Scrapling 的 PyPI 页面](https://pypi.org/project/scrapling/) 和 [Docker 镜像页面](https://hub.docker.com/r/pyd4vinci/scrapling) 顶部。

### 2. [Gold 档位](https://github.com/sponsors/D4Vinci/sponsorships?tier_id=591422)（$200/月）

权益：

1. 你的 Logo 将展示在 [Scrapling 项目页顶部](https://github.com/D4Vinci/Scrapling?tab=readme-ov-file#sponsors)。
2. 同一个 Logo 也会以相同方式展示在 [Scrapling 的 PyPI 页面](https://pypi.org/project/scrapling/) 和 [Docker 镜像页面](https://hub.docker.com/r/pyd4vinci/scrapling) 顶部。
3. 你的 Logo 还会作为顶级赞助商展示在 [Scrapling 官网首页](https://scrapling.readthedocs.io/en/latest/)。

### 3. [Platinum 档位](https://github.com/sponsors/D4Vinci/sponsorships?tier_id=586646)（$300/月）

权益：

1. 你的 Logo 将以特殊位置展示在 [Scrapling 项目页最顶部](https://github.com/D4Vinci/Scrapling?tab=readme-ov-file#platinum-sponsors)，并附带一段不超过 25 个词的介绍。
2. 同一个 Logo 也会以相同方式展示在 [PyPI 页面](https://pypi.org/project/scrapling/) / [Docker 页面](https://hub.docker.com/r/pyd4vinci/scrapling)。
3. 你的 Logo 还会在 [Scrapling 官网首页](https://scrapling.readthedocs.io/en/latest/) 作为顶级赞助商获得特殊展示位。
4. 你将在我们的 Discord 服务器中获得合作伙伴身份，并在 Twitter 页面与 Discord 服务器中获得公告宣传。
5. 你会在每次发布说明的结尾获得鸣谢。
