# MCP Server API 参考

**Scrapling MCP Server** 通过 Model Context Protocol (MCP) 为网页抓取提供九个强大工具。这个服务将 Scrapling 的能力直接集成到 AI 聊天机器人和 Agent 中，使你能够以对话方式进行网页抓取，并利用高级反爬绕过能力。

你可以通过运行以下命令启动 MCP Server：

```bash
scrapling mcp
```

或者直接导入服务类：

```python
from scrapling.core.ai import ScraplingMCPServer

server = ScraplingMCPServer()
server.serve(http=False, host="0.0.0.0", port=8000)
```
