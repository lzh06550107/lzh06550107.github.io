# Response 类 API 参考

`Response` 类封装了所有 fetcher 返回的 HTTP 响应，提供对状态码、headers、body、cookies 以及用于解析内容的 `Selector` 的访问能力。

你可以像下面这样导入 `Response` 类：

```python
from scrapling.engines.toolbelt.custom import Response
```
