Hermes 附带了一个庞大的内置技能库，在安装时会被复制到 `~/.hermes/skills/` 中。下面列出的每个技能都链接到一个专有页面，其中包含其完整的定义、设置和用法。

Hermes 也会在运行 `hermes update` 时同步捆绑的技能，但同步清单（manifest）会尊重本地的删除和用户进行的编辑。如果这里列出的某个技能在您配置文件的 `~/.hermes/skills/` 树中缺失，它依然随 Hermes 一起附带；您可以通过 `hermes skills reset <name> --restore` 来恢复它。

如果某个技能在此列表中缺失但存在于仓库中，则该目录会由 `website/scripts/generate-skill-docs.py` 重新生成。
