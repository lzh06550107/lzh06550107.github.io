Hermes Agent 功能强大 —— 它可以是 CLI 助手、Telegram/Discord 机器人、任务自动化工具、强化学习（RL）训练平台等等。本页面将根据你的经验水平和目标，帮助你确定从哪里开始以及该阅读哪些内容。

:::tip[从这里开始]
如果你还没有安装 Hermes Agent，请先阅读 [安装指南](https://hermes-agent.nousresearch.com/docs/zh-Hans/docs/getting-started/installation)，然后完成 [快速入门](https://hermes-agent.nousresearch.com/docs/zh-Hans/docs/getting-started/quickstart)。下文所有内容均假设你已拥有一个可以运行的安装环境。
:::

## 如何使用本页面

* **了解自己的水平？** 直接跳转到 [按经验水平划分](https://hermes-agent.nousresearch.com/docs/zh-Hans/getting-started/learning-path#by-experience-level) 表格，按照对应等级的阅读顺序进行学习。
* **有明确的目标？** 跳过表格，直接查看 [按使用场景划分](https://hermes-agent.nousresearch.com/docs/zh-Hans/getting-started/learning-path#by-use-case)，找到匹配的方案。
* **随便看看？** 查看 [核心功能概览](https://hermes-agent.nousresearch.com/docs/zh-Hans/getting-started/learning-path#core-functionalities) 表格，快速了解 Hermes Agent 的所有能力。

3. [CLI 使用](https://hermes-agent.nousresearch.com/docs/zh-Hans/docs/getting-started/cli-usage)

:::

## 下一步读什么？

根据你当前的进度：

* **刚完成安装？** → 前往 [快速入门](https://hermes-agent.nousresearch.com/docs/zh-Hans/docs/getting-started/quickstart) 开启你的第一次对话。
* **已完成快速入门？** → 阅读 [CLI 使用](https://hermes-agent.nousresearch.com/docs/zh-Hans/docs/getting-started/cli-usage) 和 [配置](https://hermes-agent.nousresearch.com/docs/zh-Hans/docs/getting-started/configuration) 来定制你的环境。
* **熟悉基础操作了？** → 探索[工具](https://hermes-agent.nousresearch.com/docs/zh-Hans/docs/getting-started/tools)、[技能](https://hermes-agent.nousresearch.com/docs/zh-Hans/docs/getting-started/skills)和[记忆](https://hermes-agent.nousresearch.com/docs/zh-Hans/docs/getting-started/memory)，解锁 Agent 的全部能力。
* **正在为团队进行设置？** → 阅读[安全性](https://hermes-agent.nousresearch.com/docs/zh-Hans/docs/getting-started/security)和[会话](https://hermes-agent.nousresearch.com/docs/zh-Hans/docs/getting-started/sessions)，了解访问控制和对话管理。
* **准备好进行开发了？** → 跳转到[开发者指南](https://hermes-agent.nousresearch.com/docs/zh-Hans/docs/getting-started/developer-guide)深入了解内部机制并开始贡献代码。
* **想要实战案例？** → 查看[指南](https://hermes-agent.nousresearch.com/docs/zh-Hans/docs/getting-started/guides)部分，获取真实项目案例和技巧。

:::tip[提示]
你不需要阅读所有内容。选择与你目标匹配的路径，按顺序点击链接，你将很快上手。你可以随时回到本页面寻找下一步操作。
:::
