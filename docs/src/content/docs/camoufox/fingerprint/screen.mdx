欺骗屏幕尺寸、像素深度和窗口位置。

## 属性 (Properties)

| 属性 (Property) | 类型 (Type) | 说明 (Description) |
| --- | --- | --- |
| `screen.availHeight` | uint | 屏幕的可用高度 |
| `screen.availWidth` | uint | 屏幕的可用宽度 |
| `screen.availTop` | uint | 可用区域顶部的 Y 坐标 |
| `screen.availLeft` | uint | 可用区域左侧的 X 坐标 |
| `screen.height` | uint | 屏幕的总高度 |
| `screen.width` | uint | 屏幕的总宽度 |
| `screen.colorDepth` | uint | 屏幕的色彩深度 |
| `screen.pixelDepth` | uint | 屏幕的像素深度 |
| `screen.pageXOffset` | double | 水平滚动位置 |
| `screen.pageYOffset` | double | 垂直滚动位置 |

:::note
`screen.colorDepth` 和 `screen.pixelDepth` 是同义词。
:::
