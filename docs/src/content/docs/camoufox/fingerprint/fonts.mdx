可以通过 `fonts` 配置属性将要用于 Camoufox 的字体传递过去。

| 属性 (Property) | 类型 (Type) | 说明 (Description) |
| --- | --- | --- |
| `fonts` | array | 要使用的字体名称列表 |
| `fonts:spacing_seed` | uint | 用于字体度量间距随机化的种子 |

默认情况下，Camoufox 捆绑了默认的 Windows 11 22H2 字体、macOS Sonoma 字体以及 TOR 浏览器包中使用的 Linux 字体。Camoufox 会根据您欺骗的 User-Agent 操作系统（即传递给 `navigator.userAgent` 的值）自动添加与之关联的默认字体：

## 新字体 (New fonts)

可以通过将其他字体复制到 Camoufox 的 `fonts/` 目录中，或者通过将它们安装到您的系统中来添加它们。

:::tip
建议您 **随机** 向 `fonts` 配置属性传递自定义字体，以避免字体指纹识别！
:::

## 字体度量 (Font Metrics)

Camoufox 具有内置机制，可防止通过字体度量（font metrics）和 unicode 字形进行指纹识别：

其工作原理是将每个字母的间距随机偏移 0-0.1 像素之间的值。
