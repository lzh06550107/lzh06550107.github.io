伪装 HTML body 元素的尺寸。

:::warning
虽然已经实现了对 `document.body` 的伪装，但更建议直接设置 `window.innerWidth` 和 `window.innerHeight`。
:::

## 属性

| 属性 | 类型 | 说明 |
|---|---|---|
| `document.body.clientWidth` | uint | 文档 body 的宽度 |
| `document.body.clientHeight` | uint | 文档 body 的高度 |
| `document.body.clientTop` | uint | 文档 body 上边框的宽度 |
| `document.body.clientLeft` | uint | 文档 body 左边框的宽度 |
