# Hooks 钩子

> 在 Codex 生命周期中运行确定性脚本

Hooks 是 Codex 的可扩展框架。它们允许你将自定义脚本注入到智能体循环中，实现以下功能：

- 将会话发送到自定义日志/分析引擎
- 扫描团队提示词，阻止意外粘贴 API 密钥
- 自动总结对话以创建持久记忆
- 在会话轮次停止时运行自定义验证检查
- 在特定目录时自定义提示

## 启用和禁用

Hooks 默认启用。在 `config.toml` 中关闭：

```toml
[features]
hooks = false
```

## 查找 Hooks

Codex 在活动配置层附近发现 hooks，支持两种形式：

| 位置 | 说明 |
| --- | --- |
| `~/.codex/hooks.json` | 用户级钩子 |
| `~/.codex/config.toml` | `[hooks]` 内联表 |
| `<repo>/.codex/hooks.json` | 项目级钩子（需信任） |
| `<repo>/.codex/config.toml` | 项目级内联钩子（需信任） |

## 事件类型

| 事件 | 触发时机 | 支持 matcher |
| --- | --- | --- |
| **SessionStart** | 会话启动/恢复/清除 | 启动来源 |
| **PreToolUse** | 工具使用前（拦截 Bash、编辑、MCP） | 工具名称 |
| **PermissionRequest** | 即将请求审批时 | 工具名称 |
| **PostToolUse** | 工具产生输出后 | 工具名称 |
| **UserPromptSubmit** | 用户提交提示后 | 不支持 |
| **Stop** | 会话停止时 | 不支持 |

## 配置示例

**JSON 格式（hooks.json）：**
```json
{
  "hooks": {
    "PreToolUse": [
      {
        "matcher": "Bash",
        "hooks": [
          {
            "type": "command",
            "command": "python3 ~/.codex/hooks/pre_tool_use_policy.py",
            "statusMessage": "正在检查 Bash 命令"
          }
        ]
      }
    ],
    "PostToolUse": [
      {
        "matcher": "Bash",
        "hooks": [
          {
            "type": "command",
            "command": "python3 ~/.codex/hooks/post_tool_use_review.py",
            "timeout": 30
          }
        ]
      }
    ]
  }
}
```

**TOML 格式（config.toml）：**
```toml
[[hooks.PreToolUse]]
matcher = "^Bash$"

[[hooks.PreToolUse.hooks]]
type = "command"
command = '/usr/bin/python3 "$(git rev-parse --show-toplevel)/.codex/hooks/pre_tool_use_policy.py"'
timeout = 30
statusMessage = "正在检查 Bash 命令"
```

## 管理 Hooks

使用 `/hooks` 命令在 CLI 中检查钩子来源、审查新钩子、信任钩子或禁用单个非托管钩子。

| 类型 | 说明 |
| --- | --- |
| **托管钩子** | 来自系统/MDM/企业，受策略信任，不可禁用 |
| **非托管钩子** | 用户级/项目级，需要审查和信任后才能运行 |
