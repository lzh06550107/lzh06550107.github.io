# 插件 (Plugins)

> 在 Codex 中使用插件添加可复用的工作流程，集成技能和应用。

## 概述

插件将技能、应用集成和 MCP 服务器打包为 Codex 的可复用工作流程。

扩展 Codex 的能力，例如：

- 安装 Gmail 插件，让 Codex 读取和管理 Gmail。
- 安装 Google Drive 插件，在 Drive、文档、表格和幻灯片之间协作。
- 安装 Slack 插件，总结频道消息或起草回复。

一个插件可以包含：

- **技能 (Skills)**：针对特定工作类型的可复用指令。Codex 可以在需要时加载它们，以遵循正确的步骤并使用正确的参考或辅助脚本。
- **应用 (Apps)**：连接 GitHub、Slack 或 Google Drive 等工具，让 Codex 可以从中读取信息并执行操作。
- **MCP 服务器**：为 Codex 提供额外工具或共享信息的服务，通常来自本地项目之外的系统。

更多插件功能即将推出。

## 使用和安装插件

### Codex 应用中的插件目录

在 Codex 应用中打开 **插件 (Plugins)** 以浏览和安装精选插件。

<LinkButton href="https://developers.openai.com/codex/plugins" variant="secondary">
  在 Codex 应用中打开插件页面
</LinkButton>

### CLI 中的插件目录

在 Codex CLI 中，运行以下命令打开插件列表：

```text
codex
/plugins
```

CLI 插件浏览器按市场分组插件。使用市场标签页切换来源，打开插件查看详情，安装或卸载市场条目，在已安装插件上按 `Space` 键切换其启用状态。

<LinkButton href="https://developers.openai.com/codex/plugins" variant="secondary">
  在 Codex CLI 中打开插件列表
</LinkButton>

### 安装和使用插件

打开插件目录后：

1. 搜索或浏览插件，然后打开其详情。
2. 点击安装按钮。在应用中，选择加号按钮或 **添加到 Codex**。在 CLI 中，选择 `Install plugin`。
3. 如果插件需要外部应用，在提示时连接它。有些插件会在安装时要求认证，有些则等到首次使用时才要求。
4. 安装完成后，启动新会话并让 Codex 使用该插件。

安装插件后，你可以直接在提示窗口中使用它：

### 权限和数据共享机制

安装插件会使其工作流程在 Codex 中可用，但你现有的[审批设置](/codex/agent-approvals-security)仍然适用。任何连接的外部服务仍受其自身的认证、隐私和数据共享政策的约束。

- 捆绑的技能在安装插件后立即可用。
- 如果插件包含应用，Codex 可能会在设置期间或首次使用时提示你在 ChatGPT 中安装或登录这些应用。
- 如果插件包含 MCP 服务器，它们可能需要额外的设置或认证才能使用。
- 当 Codex 通过捆绑的应用发送数据时，该应用的服务条款和隐私政策适用。

### 移除或禁用插件

要移除插件，请从插件浏览器中重新打开它，然后选择 **卸载插件 (Uninstall plugin)**。

卸载插件会从 Codex 中移除插件包，但捆绑的应用仍然保持安装状态，直到你在 ChatGPT 中管理它们。

如果你想保留插件但暂时关闭它，请在 `~/.codex/config.toml` 中将其条目设置为 `enabled = false`，然后重启 Codex：

```toml
[plugins."gmail@openai-curated"]
enabled = false
```

## 构建你自己的插件
