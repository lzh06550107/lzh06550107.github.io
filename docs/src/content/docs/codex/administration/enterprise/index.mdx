# Enterprise 管理员设置

> 为企业 ChatGPT Enterprise 工作区设置 Codex

本指南面向希望为其工作区设置 Codex 的 ChatGPT Enterprise 管理员。

## 企业级安全与隐私

Codex 支持 ChatGPT Enterprise 安全功能，包括：
- 企业数据不用于训练
- App、CLI 和 IDE 零数据保留（代码留在开发者环境中）
- 数据驻留和保留遵循 ChatGPT Enterprise 政策
- 精细的用户访问控制
- 静态加密（AES-256）和传输加密（TLS 1.2+）
- 通过 ChatGPT Compliance API 进行审计日志

## 7 步部署流程

### 步骤 1：在工作区中启用 Codex

在 ChatGPT Enterprise 工作区设置中配置 Codex 访问权限。

![Enterprise Codex 管理员设置界面](/images/codex/administration/enterprise/codex_enterprise_admin.png)

**Codex Local（本地）：** 默认启用。授权用户可使用 Codex 桌面应用、CLI 和 IDE 扩展。

![本地切换配置](/images/codex/administration/enterprise/local-toggle-config.png)

**Codex Cloud（云端）：** 需启用 ChatGPT GitHub Connector，连接 GitHub 仓库。

![云端切换配置](/images/codex/administration/enterprise/cloud-toggle-config.png)

### 步骤 2：设置自定义角色（RBAC）

使用 RBAC 控制 Codex Local 和 Codex Cloud 的细粒度权限。

创建 **Codex Admin** 组和 **Codex Users** 组的分离模式。

![RBAC 自定义角色配置](/images/codex/administration/enterprise/rbac_custom_roles.png)

### 步骤 3：配置 Codex Local 要求

管理员可从 Codex Policies 页面部署 `requirements.toml` 策略，向不同群组应用不同的本地 Codex 约束。

![策略与配置页面](/images/codex/administration/enterprise/policies_and_configurations_page.png)

![策略示例](/images/codex/administration/enterprise/example_policy.png)

![策略查找](/images/codex/administration/enterprise/policy_lookup.png)

### 步骤 4：使用 Team Config 标准化本地配置

将 Team Config 设置检入仓库的 `.codex` 目录，团队获得一致行为。

### 步骤 5：配置 Codex Cloud 使用

连接 GitHub 仓库、配置 IP 地址白名单、启用代码审查和 Codex Security。

![代码审查设置概览](/images/codex/administration/enterprise/code_review_settings_overview.png)

![自动代码审查设置](/images/codex/administration/enterprise/auto_code_review_settings.png)

![审查触发条件](/images/codex/administration/enterprise/review_triggers.png)

### 步骤 6：建立治理和可观测性

使用 Analytics Dashboard（自服务）、Analytics API（编程报表）和 Compliance API（审计导出）。

![Analytics Dashboard](/images/codex/administration/enterprise/analytics.png)

![分析密钥配置](/images/codex/administration/enterprise/codex_analytics_key.png)

### 步骤 7：确认和验证

验证用户登录、MFA/SSO、RBAC 策略和治理数据。
