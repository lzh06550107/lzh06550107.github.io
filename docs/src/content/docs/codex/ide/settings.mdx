使用这些设置来自定义 Codex IDE 扩展。

## 更改设置

要更改设置，请按以下步骤操作：

1. 打开编辑器设置。
2. 搜索 `Codex` 或设置名称。
3. 更新值。

Codex IDE 扩展使用 Codex CLI。某些行为（如默认模型、审批和沙箱设置）请在共享的 `~/.codex/config.toml` 文件中配置，而不是在编辑器设置中。请参阅 [配置基础](/codex/configuration/config-basic)。

该扩展也会遵循 VS Code 内置的聊天字体设置，应用于 Codex 对话界面。

## 设置参考

| 设置项 | 描述 |
|---|---|
| `chat.fontSize` | 控制 Codex 侧边栏中的聊天文本大小，包括对话内容和输入框。 |
| `chat.editor.fontSize` | 控制 Codex 对话中代码渲染内容的大小，包括代码片段和差异对比。 |
| `chatgpt.cliExecutable` | 仅限开发用途：Codex CLI 可执行文件的路径。除非你正在积极开发 Codex CLI，否则无需设置此项。如果手动设置，扩展的某些部分可能无法按预期工作。 |
| `chatgpt.commentCodeLensEnabled` | 在待办事项注释上方显示 CodeLens，方便使用 Codex 完成它们。 |
| `chatgpt.localeOverride` | Codex UI 的首选语言。留空则自动检测。 |
| `chatgpt.openOnStartup` | 扩展启动完成后自动聚焦 Codex 侧边栏。 |
| `chatgpt.runCodexInWindowsSubsystemForLinux` | 仅限 Windows：当 Windows Subsystem for Linux (WSL) 可用时，在 WSL 中运行 Codex。当你的仓库和工具链位于 WSL2 中或需要 Linux 原生工具时使用此选项。否则，Codex 可以在 Windows 上通过 Windows 沙箱原生运行。更改此设置会重新加载 VS Code 以应用更改。 |
