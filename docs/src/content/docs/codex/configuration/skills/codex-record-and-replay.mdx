:::note
Record & Replay 可在 macOS 上使用。初始可用性不包括欧洲经济区、英国和瑞士。Computer Use 也必须可用并已启用。
:::

Record & Replay 允许你在 Mac 上演示一个工作流，并将其转换为可复用的技能。当工作流具有重复性、依赖你的偏好，或者比起用提示词描述更适合直接展示时，可以使用它。

例如，你可以录制如何提交费用报销、预订停车位、创建一个配置正确的 issue、发布视频，或者下载一份周期性报告。Codex 可以将这个模式打包成一个技能，之后你可以结合 Computer Use、浏览器操作、已连接的插件，或它们的组合再次使用。

## 开始之前

选择一个你已经知道如何完成的工作流。当步骤稳定且成功标准清晰时，Record & Replay 的效果最好。

## 开始录制

1. 在 Codex 应用中打开 Plugins。
2. 打开 `+` 菜单。
3. 选择 Record a skill。
4. 查看建议的提示词，向 Codex 提供任何有帮助的上下文，然后提交。
5. 当 Codex 请求录制你的操作权限时，在准备好演示该工作流后批准请求。
6. 在你的 Mac 上执行该工作流。
7. 完成后，从菜单栏、覆盖层停止录制，或者告诉 Codex 你已经完成。

在录制期间，Codex 会观察学习该工作流所需的操作和窗口内容。录制会一直持续，直到你停止它。请让录制内容聚焦于你希望 Codex 学习的任务。

停止录制后，Codex 会检查捕获到的工作流并起草一个技能。该技能会说明何时使用该工作流、它需要哪些输入、应遵循哪些步骤，以及如何验证结果。你也可以要求 Codex 进一步优化该技能。

## 重放工作流

启动一个新线程，并要求 Codex 使用生成的技能。向它提供这一次不同的值，例如要上传的文件、要创建的 issue，或者报告的日期范围。

Codex 会将该技能作为任务的可复用上下文。然后，它可以使用当前环境中可用的工具完成该工作流，包括 Computer Use、浏览器操作和已安装的插件。

## 更好录制的提示

- 保持演示简短且完整。
- 在开始录制之前，告诉 Codex 你的目标，以及在不同技能使用场景中可能变化的任何具体输入。
- 使用真实合理的输入，但避免使用机密和敏感数据。
- 录制后优化该技能，指出重要的隐藏偏好，例如命名约定、字段默认值或决策点。
- 在工作流完成时停止录制，而不是继续进入无关的清理工作。

## 何时构建另一个插件

Record & Replay 是一种从演示的工作流快速创建技能的方式。如果你希望在团队内分发一个独立、稳定的软件包，打包多个技能，包含应用集成，添加 MCP 服务器，或者管理安装元数据，请将该工作流打包为自己的插件。请参阅 [构建插件](https://developers.openai.com/codex/plugins/build)。

## 故障排除

### 我看不到 Record & Replay

如果你的组织使用 `requirements.toml` 管理 Codex，`[features].computer_use` 要求也会控制 Record & Replay。设置 `computer_use = false` 会使这两个功能都不可用。
