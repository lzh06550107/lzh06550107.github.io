## 概述 (Overview)

插件将技能、应用集成和 MCP 服务器捆绑到 Codex 的可复用工作流中。

扩展 Codex 的功能，例如：

* 安装 Codex Security 插件以扫描授权代码并确认合理的漏洞发现。
* 安装 Gmail 插件以允许 Codex 阅读和管理 Gmail。
* 安装 Google Drive 插件以跨 Drive、Docs、Sheets 和 Slides 进行工作。
* 安装 Slack 插件以总结频道或撰写回复草稿。
* 安装 [Sites](https://developers.openai.com/codex/sites) 以创建和部署托管网站、Web 应用和游戏。

一个插件可以包含：

* **技能 (Skills)：** 针对特定类型工作的可复用指令。Codex 可以在需要时加载它们，以便它遵循正确的步骤并为任务使用正确的参考资料或辅助脚本。
* **应用 (Apps)：** 连接到 GitHub、Slack 或 Google Drive 等工具的连接，以便 Codex 可以从这些工具中读取信息并在其中采取行动。
* **MCP 服务器 (MCP servers)：** 为 Codex 提供访问更多工具或共享信息权限的服务，这些服务通常来自本地项目之外的系统。

您可以通过市场源（例如项目或团队的存储库市场）发布插件来共享它们。有关市场设置、打包和分发指南，请参见 [构建插件](https://developers.openai.com/codex/plugins/build)。

## 使用和安装插件 (Use and install plugins)

### Codex 应用中的插件目录 (Plugin Directory in the Codex app)

在 Codex 应用中打开 **Plugins** 以浏览和安装精选插件。

插件目录将插件分为以下几类：

* **由 OpenAI 精选 (Curated by OpenAI)：** 面向所有 Codex 用户提供的突出显示的插件。
* **与您共享 (Shared with you)：** 由您的 ChatGPT 工作空间中的其他成员共享的插件。
* **由您创建 (Created by you)：** 您创建或添加到您自己工作空间的插件。

### CLI 中的插件目录 (Plugin directory in the CLI)

在 Codex CLI 中，运行以下命令以打开插件列表：

```text
codex
/plugins
```

CLI 插件浏览器按市场对插件进行分组。使用市场标签页来切换源，打开插件以检查详细信息，安装或卸载市场条目，并在已安装的插件上按 Space 键来切换其启用状态。

### 安装和使用插件 (Install and use a plugin)

打开插件目录后：

1. 搜索或浏览插件，然后打开其详细信息。
2. 选择安装按钮。在应用中，选择加号按钮或 **Add to Codex**。在 CLI 中，选择 `Install plugin`。
3. 如果插件需要外部应用，请在收到提示时进行连接。某些插件会要求您在安装期间进行身份验证。其他插件则会等到您第一次使用它们时。
4. 安装完成后，启动一个新线程并要求 Codex 使用该插件。

安装插件后，您可以直接在提示词窗口中使用它：

直接描述任务

- 要求您想要的结果，例如“总结今天未读的 Gmail 线程”或“从 Google Drive 获取最新的发布说明”。
- 当您希望 Codex 为任务选择正确的已安装工具时，请使用此方式。

选择特定插件

- 输入 @ 以显式调用插件或其捆绑的技能之一。
- 当您想要具体指定 Codex 应当使用哪个插件或技能时，请使用此方式。参见 Codex 应用命令和技能。

### 权限和数据共享的工作原理 (How permissions and data sharing work)

安装插件使其工作流在 Codex 中可用，但您现有的 [审批设置](https://developers.openai.com/codex/agent-approvals-security) 仍然适用。任何连接的外部服务仍受其自身的身份验证、隐私和数据共享政策的约束。

* 捆绑的技能在您安装插件后立即生效。
* 如果插件包含应用，Codex 可能会在设置期间或您第一次使用它们时，提示您在 ChatGPT 中安装或登录这些应用。
* 如果插件包含 MCP 服务器，它们可能需要额外的设置或身份验证才能使用。
* 当 Codex 通过捆绑的应用发送数据时，该应用的条款和隐私政策将适用。

### 移除或关闭插件 (Remove or turn off a plugin)

要移除插件，请从插件浏览器中重新打开它，然后选择 **Uninstall plugin**。

卸载插件会从 Codex 中移除插件包，但捆绑的应用将保持安装状态，直到您在 ChatGPT 中对其进行管理。

如果您想保持插件安装但将其关闭，请将其在 `~/.codex/config.toml` 中的条目设置为 `enabled = false`，然后重启 Codex：

```toml
[plugins."gmail@openai-curated"]
enabled = false
```

### 构建您自己的插件 (Build your own plugin)

如果您想创建、测试或分发您自己的插件，请参见 [构建插件](https://developers.openai.com/codex/plugins/build)。该页面涵盖了本地脚手架、手动市场设置、工作空间共享、插件清单以及打包指南。
