# 智能体技能 (Skills)

> 为 Codex 赋予新能力和专业知识

使用智能体技能为 Codex 扩展任务特定的能力。一个技能将指令、资源和可选的脚本打包，使 Codex 能够可靠地遵循工作流程。技能基于 [开放智能体技能标准](https://github.com/openai/open-agents-skill-standard) 构建。

技能是可复用工作流的**创作格式**。插件是在 Codex 中分发可复用技能和应用的**可安装分发单元**。先用技能设计工作流本身，然后打包为插件供其他开发者安装。

技能在 Codex CLI、IDE 扩展和 Codex 桌面应用中均可使用。

![在 IDE 中选择技能](/images/codex/configuration/skills/skills-selector-ide-light.webp)

## Codex 如何使用技能

技能使用 **SKILL.md** 文件定义，包含：

- **指令**：告诉 Codex 该做什么的提示
- **资源**：模板、参考文档和示例
- **脚本**：可运行的动作脚本

当技能被调用时，Codex 将 SKILL.md 加载到上下文中，使其按照技能定义的方式工作。

## 创建技能

### 基本结构

```
my-skill/
├── SKILL.md        # 技能定义（必需）
├── assets/         # 资源文件
└── scripts/        # 可运行脚本
```

### SKILL.md 示例

```markdown
---
name: my-skill
description: 描述该技能的作用和使用时机
---

# 我的技能

## 使用场景
当你需要做 X 时使用此技能。

## 指令
1. 首先执行 A
2. 然后执行 B
3. 最后验证 C

## 约束
- 不要修改 Y 文件
- 遵循 Z 标准
```

## 保存技能的位置

| 位置 | 作用域 | 说明 |
| --- | --- | --- |
| `~/.agents/skills/` | **个人** | 你自己的本地技能 |
| `<repo>/.agents/skills/` | **团队/仓库** | 团队共享技能，非常适合新成员入职 |

## 使用插件分发技能

当技能成熟且希望他人安装时，将其打包为插件。插件是可安装的分发单元，包含技能和可选的应用。

## 安装精选技能

Codex 提供了一些预置的精选技能，可通过命令安装。

## 启用或禁用技能

在 Codex 桌面应用的设置中管理技能，或通过 CLI 命令控制。

## 最佳实践

| 原则 | 说明 |
| --- | --- |
| **每个技能只做一件事** | 保持技能范围聚焦，从 2-3 个具体用例开始 |
| **定义清晰的输入和输出** | 明确技能接收什么、产出什么 |
| **描述要精准** | 说明技能做什么以及何时使用，包含用户可能说的触发词 |
| **迭代改进** | 先让一个代表性任务跑通，再将其转化为技能 |
| **不要一开始覆盖所有边界情况** | 从最常用的路径开始 |

### 适合技能的重复性工作

- 日志分类
- 发布说明撰写
- 对照清单的 PR 审查
- 迁移规划
- 遥测或事故总结
- 标准调试流程

:::tip
`$skill-creator` 技能是搭建技能初版的最佳起点。先本地迭代，准备好广泛分享时再打包为插件。
:::
