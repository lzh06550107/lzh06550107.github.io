# 功能成熟度

> 如何理解 Codex 文档和发布中的功能成熟度等级

某些 Codex 功能在发布时会附带成熟度标签，以便你了解每个功能的可靠性、可能的变化以及预期的支持水平。

| 成熟度 | 含义 | 建议 |
| --- | --- | --- |
| **开发中** | 尚未准备好使用 | 不要使用 |
| **实验性** | 不稳定，OpenAI 可能移除或变更 | 风险自负 |
| **Beta** | 已准备好进行广泛测试；大部分已完成，但某些方面可能根据用户反馈发生变化 | 适合评估和试点；预期有小变化 |
| **稳定** | 完全支持、有文档、可广泛使用；行为和配置保持一致 | 适合生产使用；移除通常会经过弃用流程 |
