# 开源

> Codex 的开源组件及贡献方式

OpenAI 在 GitHub 上公开开发 Codex 的关键部分，你可以跟踪进展、报告问题和贡献改进。

## 开源组件

| 组件 | 位置 | 说明 |
| --- | --- | --- |
| **Codex CLI** | [openai/codex](https://github.com/openai/codex) | Codex 开源开发的主仓库 |
| **Codex SDK** | [openai/codex/sdk](https://github.com/openai/codex/sdk) | SDK 源码 |
| **Codex App Server** | [openai/codex](https://github.com/openai/codex) | App Server 源码 |
| **Skills** | [openai/skills](https://github.com/openai/skills) | 可复用的 Codex 技能 |
| **IDE 扩展** | — | 未开源 |
| **Codex Web** | — | 未开源 |
| **Cloud 环境** | [openai/codex-universal](https://github.com/openai/codex-universal) | Codex 云使用的基础环境 |

## 报告问题和请求功能

- **Bug 报告和功能请求：** [openai/codex/issues](https://github.com/openai/codex/issues)
- **讨论论坛：** [openai/codex/discussions](https://github.com/openai/codex/discussions)

提交问题时请注明所使用的组件（CLI、SDK、IDE 扩展或 Web）和版本。
