> **适用于你所有代码场景的智能体**

Codex 是 OpenAI 为软件开发打造的编程智能体。ChatGPT Plus、Pro、Business、Edu 和 Enterprise 套餐均包含 Codex。它能帮助你：

![Codex 应用界面——项目侧边栏、线程列表和审查面板](/images/codex/app/codex-app-basic-light.webp)

## 主要功能

### ✍️ 编写代码

描述你想要构建的内容，Codex 就会生成符合你意图的代码，并能自适应你现有项目的结构和编码规范。

### 🔍 理解不熟悉的代码库

Codex 能够阅读和解释复杂或遗留代码，帮助你快速理解团队是如何组织系统的。

### 👁️ 审查代码

Codex 会分析你的代码，识别潜在缺陷、逻辑错误和未处理的边界情况。

### 🐛 调试与修复问题

当出现问题时，Codex 帮助你追踪故障链路、诊断根本原因，并建议有针对性的修复方案。

### 🤖 自动化开发任务

Codex 可以运行重复性的工作流程，例如重构、测试、迁移和项目初始化等任务，让你能够专注于更高层次的工程工作。
