> 在 IDE、终端或云端开始使用 Codex

所有 ChatGPT 套餐均包含 Codex。你也可以使用 OpenAI API 密钥登录，通过 API 额度来使用 Codex。

## 安装方式

请选择你偏好的使用方式：

<Tabs>
  <TabItem label="App" icon="mobile">
    Codex 桌面应用支持 macOS 和 Windows。大多数功能在两个平台上均可使用，平台相关的例外情况会在相关文档中注明。

    ### 1. 下载并安装 Codex 桌面应用

    下载适用于 macOS 或 Windows 的 Codex 桌面应用。

    <LinkButton href="https://get.microsoft.com/installer/download/9PLM9XGG6VKS?cid=website_cta_psi" variant="primary" size="lg">
      Windows 下载
    </LinkButton>

    不同的操作系统：
    * [macOS 下载](https://persistent.oaistatic.com/codex-app-prod/Codex.dmg)
    * [Linux 下载](https://openai.com/form/codex-app/)

    ### 2. 打开 Codex 并登录

    下载安装完成后，打开 Codex 并使用你的 ChatGPT 账户或 OpenAI API 密钥登录。

    :::caution
    如果使用 API 密钥登录，部分功能（如云端线程）可能不可用。
    :::

    ### 3. 选择一个项目

    选择你想让 Codex 工作的项目文件夹。如果你之前使用过 Codex，会看到过去的工作项目列表。

    ### 4. 发送第一条消息

    选择项目后，确保选中 **本地**（Local）模式，让 Codex 在你的机器上工作，然后发送第一条消息给 Codex。

    你可以询问 Codex 关于项目或计算机的任何问题。例如：

    - ![🧠](/images/codex/colorcons/brain.png) 告诉我这个项目是做什么的
    - ![🎮](/images/codex/colorcons/gamepad.png) 在这个仓库中构建一个经典的贪吃蛇游戏
    - ![🔍](/images/codex/colorcons/search.png) 在我的代码库中查找并修复 bug

    如果需要更多灵感，可以浏览 [Codex 使用场景](/codex/getting-started/use-cases)。如果你是 Codex 新手，建议阅读 [最佳实践指南](/codex/learn/best-practices)。
  </TabItem>

  <TabItem label="IDE 扩展" icon="seti:code">
    为你的 IDE 安装 Codex 扩展。

    ### 1. 安装 Codex 扩展

    为你的编辑器下载 Codex 扩展：

    - [下载适用于 Visual Studio Code](vscode:extension/openai.chatgpt)
    - [下载适用于 Cursor](cursor:extension/openai.chatgpt)
    - [下载适用于 Windsurf](windsurf:extension/openai.chatgpt)
    - [下载适用于 Visual Studio Code Insiders](https://marketplace.visualstudio.com/items?itemName=openai.chatgpt)

    ### 2. 打开 Codex 面板

    安装完成后，Codex 扩展会出现在侧边栏中（与其他扩展并列）。如果找不到，它可能隐藏在折叠区域中。你可以根据自己的偏好将 Codex 面板移到编辑器右侧。

    ### 3. 登录并开始第一个任务

    使用你的 ChatGPT 账户或 API 密钥登录即可开始使用。Codex 默认以 **智能体模式（Agent mode）** 启动，这允许它读取文件、运行命令以及在项目目录中写入更改。

    ### 4. 使用 Git 检查点

    Codex 可以修改你的代码库，因此建议在每个任务前后创建 Git 检查点，以便在需要时轻松回退更改。

      了解更多关于 Codex IDE 扩展 →
    </LinkButton>
  </TabItem>

  <TabItem label="CLI" icon="terminal">
    Codex CLI 支持 macOS、Windows 和 Linux。

    ### 1. 安装 Codex CLI

    使用 npm 安装：

    ```bash
    npm install -g @openai/codex
    ```

    使用 Homebrew 安装：

    ```bash
    brew install codex
    ```

    ### 2. 运行 `codex` 并登录

    在终端中运行 `codex` 即可开始使用。系统会提示你使用 ChatGPT 账户或 API 密钥登录。

    ### 3. 让 Codex 在当前目录工作

    认证完成后，你可以让 Codex 在当前目录中执行任务。例如：
    - 告诉我这个项目是做什么的
    - 在这个仓库中构建一个经典的贪吃蛇游戏
    - 在我的代码库中查找并修复 bug

    ### 4. 使用 Git 检查点

    Codex 可以修改你的代码库，因此建议在每个任务前后创建 Git 检查点。

    <LinkButton href="/codex/cli" variant="primary">
      了解更多关于 Codex CLI →
    </LinkButton>
  </TabItem>

  <TabItem label="云端" icon="globe">
    在 [chatgpt.com/codex](https://chatgpt.com/codex) 上云端使用 Codex。

    ### 1. 在浏览器中打开 Codex

    访问 [chatgpt.com/codex](https://chatgpt.com/codex)。你也可以通过在 GitHub PR 评论中标记 `@codex` 来将任务委托给 Codex（需要登录 ChatGPT）。

    ### 2. 设置环境

    在开始第一个任务之前，为 Codex 设置一个运行环境。打开 [环境设置](https://chatgpt.com/codex/settings/environments) 并按照步骤连接一个 GitHub 仓库。

    ### 3. 启动任务并监控进度

    环境就绪后，从 [Codex 界面](https://chatgpt.com/codex) 启动编码任务。你可以实时查看日志监控进度，也可以让任务在后台运行。

    ### 4. 审查变更并创建 PR

    任务完成后，在差异视图中审查建议的变更。你可以迭代调整结果，或直接在 GitHub 仓库中创建 Pull Request。Codex 还会提供变更预览。

    ```bash
    git fetch
    git checkout <branch-name>
    ```
