# Codex 价格方案

> Codex 已包含在你的 ChatGPT 套餐中

Codex 包含在 ChatGPT Free、Go、Plus、Pro、Business、Edu 和 Enterprise 套餐中。

## 个人方案

| 方案 | 价格 | 适用场景 |
| --- | --- | --- |
| **Free** | $0/月 | 探索 Codex 快速编码任务 |
| **Go** | $8/月 | 轻量编码任务 |
| **Plus** | $20/月 | 每周几次专注编码会话 |
| **Pro 5x** | $100/月 | 比 Plus 高 5 倍速率限制 |
| **Pro 20x** | $200/月 | 比 Plus 高 20 倍速率限制 |

**Plus 包含：**
- Web、CLI、IDE 扩展和 iOS 上的 Codex
- 云端集成（自动代码审查、Slack 集成）
- 最新模型：GPT-5.5、GPT-5.4、GPT-5.3-Codex
- GPT-5.4-mini 提高日常本地消息的使用限制
- ChatGPT 额度灵活扩展使用

**Pro 包含：**
Plus 所有功能 + 5-20 倍更多 Codex 使用量 + GPT-5.3-Codex-Spark（研究预览）

## API 密钥方案

适合 CI 等共享环境中的自动化：

- Codex 在 CLI、SDK 或 IDE 扩展中的应用
- 无云端功能（GitHub 代码审查、Slack 等）
- 延迟获取新模型（如 GPT-5.3-Codex 和 GPT-5.3-Codex-Spark）
- 仅根据 API 定价为您所消耗的 Token 付费

## 常见问题解答

### Sites 的费用是多少？

Sites 在预览期间是免费的。定价信息将在近期公布。

### 我所订购的方案有哪些使用限制？

您可以发送的 Codex 消息数量取决于所使用的模型、编码任务的规模与复杂程度，以及您是在本地还是在云端运行它们。小型脚本或常规函数可能仅消耗您额度的一小部分，而较大的代码库、长周期任务或需要 Codex 保持更多上下文的延长会话，每条消息所消耗的额度会显著增加。

GPT-5.5 在达成与 GPT-5.4 相当的效果时，所消耗的 Token 要少得多。对于大多数用户而言，其 Codex 配置运行速度更快，且能交付更高质量的结果。尽管 GPT-5.5 是一个能力显著增强的模型，但这些效率上的提升依然支撑了其较为宽松的使用限制。

本地消息和云端任务的使用限制共享同一个五小时窗口。

一旦这些功能的定价生效，Codex 的使用限制将与其他智能体（agentic）功能共享。目前，这包括针对 Plus 和 Pro 用户的 ChatGPT for Excel。

速度配置会增加所有适用模型的额度（credit）消耗，因此它们也会更快地耗尽包含在套餐内的限制额度。对于受支持的模型，快速模式（Fast mode）会以更高的速率消耗额度。关于受支持的模型和费率，请参阅“速度（Speed）”。图片生成平均也会以约 3-5 倍的速度耗尽包含的限制额度，具体取决于图片的质量和尺寸。GPT-5.3-Codex-Spark 处于研究预览阶段，仅供 ChatGPT Pro 用户使用，且在发布时无法通过 API 获取。由于它在专用的低延迟硬件上运行，其使用受独立的使用限制管辖，并可能根据需求进行调整。

### 当达到使用限制时会发生什么？

达到使用限制的 ChatGPT Plus 和 Pro 用户可以购买额外的额度来继续工作，而无需升级其现有方案。

采用弹性定价的商业版（Business）、教育版（Edu）和企业版（Enterprise）方案可以购买额外的团队空间（workspace）额度来继续使用 Codex。

如果您即将达到使用限制，也可以切换到较小的模型，以使您的使用限制维持更长时间。

所有用户还可以使用 API 密钥运行额外的本地任务，费用按标准 API 费率收取。

### 图片生成如何计入使用限制？

图片生成计入与本地消息和云端任务相同的通用 Codex 使用限制。根据图片质量和尺寸的不同，图片生成平均比没有图片生成的类似轮次快 3-5 倍消耗包含的限制额度。在您用完包含的限制额度后，图片生成也会扣除额度。

免费版（Free）方案不提供图片生成功能。当您通过 API 密钥使用 Codex 时，API 定价适用于图片生成，而不计入包含的 ChatGPT 使用限制。

### 在哪里可以查看我当前的使用限制？

您可以在 [Codex 使用情况仪表盘](https://chatgpt.com/codex/settings/usage) 中找到当前的限制。如果您想在处于激活状态的 Codex CLI 会话期间查看剩余限制，可以使用 `/status`。

### 额度（Credits）是如何运作的？

额度允许您在达到包含的使用限制后继续使用 Codex。使用量会根据您使用的模型和功能从您的可用额度中扣除，从而使您能够不间断地延长工作。

Codex 额度使用量基于 API 的 Token 费率。额度仍然是客户购买和消耗的核心定价单位，但使用量是以您的团队空间所消耗的每百万输入 Token、缓存输入 Token 和输出 Token 的额度来计算的。在这里了解关于 Token 的信息。

### 什么算作代码审查（Code Review）使用量？

代码审查使用量仅在 Codex 通过 GitHub 运行审查时适用——例如，当您在拉取请求（pull request）中标记 @Codex 进行审查，或在您的存储库上启用自动审查时。在本地或 GitHub 之外运行的审查将计入您的通用使用限制。

### 我可以做些什么来让我的使用限制维持更长时间？

上述使用限制和额度为平均费率。您可以尝试以下建议来最大化您的限制额度：

- 控制提示词的规模。对您给 Codex 的指令保持精准，但删除不必要的上下文。
- 减小 AGENTS.md 的大小。如果您在一个较大的项目上工作，可以通过将 AGENTS.md 文件嵌套在存储库中来控制注入多少上下文。
- 限制您使用的 MCP 服务器的数量。您向 Codex 添加的每个 MCP 都会增加消息的上下文，并消耗更多限制额度。在不需要时禁用 MCP 服务器。
- 针对常规任务切换到较小的模型。使用 GPT-5.4 或 GPT-5.4-mini 可以延长您的本地消息使用限制，具体取决于您切换前的模型。
