自定义包含多个互补层级：

1. **AGENTS.md** — 持久化项目指南。提供持续性的项目指导。用于构建和测试命令、审查预期、仓库特定约定、目录特定说明。当你发现重复错误、过多文件读取、重复的 PR 反馈时进行更新。

2. **技能（Skills）** — 可复用的工作流和领域专长。结构：`my-skill/SKILL.md`（必需：指令 + 元数据）、`scripts/`（可选：可执行代码）、`references/`（可选：文档）、`assets/`（可选：模板、资源）。

3. **MCP** — 访问外部工具和共享系统。架构：主机（Codex）→ 客户端（Codex 内部的 MCP 连接）→ 服务器（外部工具/上下文提供者）。MCP 服务器可以暴露：工具（操作）、资源（可读数据）、提示词（提示模板）。

4. **子智能体（Subagents）** — 将工作委派给专门的子智能体。创建具有不同角色和工具的子智能体，各自专注于自己的任务。

5. **技能 + MCP 组合** — 技能定义可重复的工作流，MCP 将它们连接到外部工具。依赖关系在 `agents/openai.yaml` 中声明。

构建顺序：AGENTS.md → 技能（Skills）→ MCP → 子智能体（Subagents）。
