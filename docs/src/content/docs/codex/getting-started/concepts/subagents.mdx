Codex 可以生成专门的子智能体，这些子智能体并行工作，同时进行探索、处理或分析任务。解决了上下文污染和上下文腐烂的问题。

## 为什么有用

- 从主会话中移除杂乱/中间输出
- 让主智能体专注于需求、决策和最终输出
- 并行运行专门的子智能体
- 返回子智能体的摘要，而非原始中间输出

## 核心术语

- **子智能体工作流**：Codex 并行运行智能体并合并结果
- **子智能体**：Codex 为特定任务生成的委托智能体
- **智能体线程**：智能体的 CLI 线程，可通过 `/agent` 检查和切换

必须手动触发（通过直接指令）。

## 模型选择

- **gpt-5.5**：最适合要求较高的多步骤工作
- **gpt-5.4-mini**：快速高效，适用于速度关键型任务（探索、只读扫描、大型文件审查）
- **gpt-5.3-codex-spark**（研究预览）：ChatGPT Pro，近乎即时的纯文本迭代
