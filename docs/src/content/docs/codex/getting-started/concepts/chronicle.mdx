---

Chronicle 是一项可选的研究预览功能，它利用最近的屏幕截图自动构建记忆，减轻重复提供上下文的负担。

## 启用方式

打开 Codex 应用设置 → 启用 Chronicle。需要 macOS 的屏幕录制和无障碍权限。

## 速率限制

后台沙盒代理会更快消耗速率配额。

## 隐私与安全

- 屏幕截图本地存储在 `$TMPDIR/chronicle/screen_recording/` 目录下
- 生成的记忆存储在 `~/.codex/memories_extensions/chronicle/` 目录下
- 截图处理完成后不会保留在服务器上

## Prompt 注入风险

屏幕内容可能被恶意指令利用。

## 故障排除

仅支持 macOS，需要 ChatGPT Pro 订阅。在欧盟、英国、瑞士地区不可用。
