自动审核（Auto-review）将沙箱边界的手动审批替换为独立的审核代理。主代理仍然在同一个沙箱内运行。

## 工作原理

1. 主代理在只读或工作区写入模式下工作
2. 当需要跨越沙箱边界时，它会请求审批
3. Codex 将该请求路由到独立的审核代理
4. 审核代理决定该操作是否应当执行
5. 如果批准，则继续执行。如果拒绝，主代理会寻找更安全的路径或停止。

## 触发条件

- 请求提升权限的 Shell 调用
- 被沙箱阻止的网络请求
- 在可写入根目录之外的文件编辑
- 需要审批的 MCP 调用
- 浏览器操作跳转到新域名

## 自动审核阻止的行为

- 将私密数据发送到不受信任的目标
- 探测凭据信息
- 大范围削弱安全性
- 存在不可逆损坏风险的破坏性操作

## 配置

默认策略位于开源 Codex 代码仓库中。可通过 `guardian_policy_config` 按企业进行自定义，或通过本地的 `[auto_review].policy` 按用户进行自定义。
