Codex 在您将其视为拥有明确上下文和清晰"完成"定义的队友时，表现最佳。

每个工作流包括：何时使用、带有示例提示的步骤、上下文说明、验证方法。

## 可用的工作流

### 1. 解释代码库

适用于入职新团队、接手服务、理解协议/数据模型。

- **IDE**：打开文件，选中代码，输入提示。
- **CLI**：启动 codex，附加文件，输入提示。

### 2. 修复 Bug

适用于您可以在本地重现的失败行为。

- **CLI**：在仓库根目录启动，提供复现步骤 + 可疑文件及约束条件。
- **IDE**：打开可疑文件及其调用者，输入提示。

### 3. 编写测试

用于明确测试范围。

- **IDE**：选中函数代码行，输入提示。
- **CLI**：使用函数名称作为提示。

### 4. 根据截图进行原型开发

适用于设计稿或 UI 参考。

- **CLI**：保存截图，附加图像，输入带约束条件的提示。

### 5. 通过实时更新迭代 UI

适用于紧密的设计循环。启动开发服务器，输入小的修改提示，实时验证。

### 6. 将重构委托到云端

适用于先精心设计再长时间实现。在本地规划，然后点击云图标进行委托。

### 7. 进行本地代码审查

在 CLI 中使用 `/review` 命令。可选择添加自定义关注指令。

### 8. 审查 GitHub PR

在 GitHub PR 评论中标记 `@codex review`。

### 9. 更新文档

识别文档文件，输入包含范围和验证要求的提示。
