使用以下命令和键盘快捷键来操作 Codex 应用。

## 键盘快捷键

| 操作 | macOS 快捷键 |
|------|-------------|
| **通用** | |
| 命令菜单 | `Cmd + Shift + P` 或 `Cmd + K` |
| 设置 | `Cmd + ,` |
| 打开文件夹 | `Cmd + O` |
| 后退导航 | `Cmd + [` |
| 前进导航 | `Cmd + ]` |
| 增大字体 | `Cmd + +` 或 `Cmd + =` |
| 减小字体 | `Cmd + -` 或 `Cmd + _` |
| 切换侧边栏 | `Cmd + B` |
| 切换差异面板 | `Cmd + Option + B` |
| 切换终端 | `Cmd + J` |
| 清空终端 | `Ctrl + L` |
| **线程** | |
| 新建线程 | `Cmd + N` 或 `Cmd + Shift + O` |
| 在线程中查找 | `Cmd + F` |
| 上一个线程 | `Cmd + Shift + [` |
| 下一个线程 | `Cmd + Shift + ]` |
| 语音输入 | `Ctrl + M` |

## 斜杠命令

斜杠命令让你无需离开线程输入框即可控制 Codex。可用命令因你的环境和访问权限而异。

### 使用斜杠命令

1. 在线程输入框中输入 `/`。
2. 从列表中选择一个命令，或继续输入以进行筛选（例如，`/status`）。

你也可以在线程输入框中输入 `$` 来显式调用技能。参见[技能](/codex/configuration/skills)。

已启用的技能也会出现在斜杠命令列表中。

### 可用的斜杠命令

| 斜杠命令 | 描述 |
|----------|------|
| `/feedback` | 打开反馈对话框，提交反馈并可选附带日志。 |
| `/mcp` | 打开 MCP 状态以查看已连接的服务器。 |
| `/plan-mode` | 切换计划模式，用于多步骤规划。 |
| `/review` | 启动代码审查模式，审查未提交的更改或与基准分支进行比较。 |
| `/status` | 显示线程 ID、上下文使用情况和速率限制。 |

## 深度链接

Codex 应用注册了 `codex://` URL 协议，使得链接可以直接打开应用的特定部分。

| 深度链接 | 打开位置 | 支持的查询参数 |
|----------|---------|---------------|
| `codex://settings` | 设置。 | 无。 |
| `codex://skills` | 技能。 | 无。 |
| `codex://automations` | 处于自动化创建模式的收件箱。 | 无。 |
| `codex://threads/<thread-id>` | 一个本地线程。`<thread-id>` 必须是 UUID。 | 无。 |
| `codex://new` | 新建线程。 | 可选：`prompt`、`originUrl`、`path`。 |

对于新建线程的深度链接：

- `prompt` 设置初始输入框文本。
- `path` 必须是本地目录的绝对路径，有效时会使该目录成为新线程的活动工作区。
- `originUrl` 尝试通过 Git 远程 URL 匹配你当前的工作区根目录之一。如果同时存在 `path` 和 `originUrl`，Codex 优先解析 `path`。
