# Codex 桌面应用

> 你的 Codex 命令中心

Codex 桌面应用是专注于并行处理 Codex 任务的桌面体验，内置工作树（worktree）支持、自动化和 Git 功能。

ChatGPT Plus、Pro、Business、Edu 和 Enterprise 套餐均包含 Codex。

![Codex 桌面应用窗口——项目侧边栏、活跃线程和审查面板](/images/codex/app/app-screenshot-light.webp)

## 快速开始

Codex 桌面应用适用于 macOS 和 Windows。大多数功能在两个平台上均可使用。

### 1. 下载并安装

- 下载适用于 macOS（Apple Silicon）
- 下载适用于 macOS（Intel）
- 下载适用于 Windows

:::note[Linux 用户]
Linux 版本正在开发中，敬请关注。
:::

### 2. 打开 Codex 并登录

安装完成后，打开 Codex 并使用 ChatGPT 账户或 OpenAI API 密钥登录。

:::caution
如果使用 API 密钥登录，部分功能（如云端线程）可能不可用。
:::

### 3. 选择一个项目

选择你想让 Codex 工作的项目文件夹。如果你之前使用过 Codex，会看到过去的工作项目列表。

### 4. 发送第一条消息

选择项目后，确保选中 **本地** 模式，让 Codex 在你的机器上工作。你可以询问关于项目或计算机的任何问题。例如：

- ![🧠](/images/codex/colorcons/brain.png) 告诉我这个项目是做什么的
- ![🎮](/images/codex/colorcons/gamepad.png) 在这个仓库中构建一个经典的贪吃蛇游戏
- ![🔍](/images/codex/colorcons/search.png) 在我的代码库中查找并修复 bug

## 使用 Codex 桌面应用

### 跨项目多任务处理

并排运行项目线程，并在它们之间快速切换。

### 工作树（Worktrees）

通过内置的 Git 工作树支持，保持并行代码变更隔离。

### 远程连接

使用 ChatGPT 移动应用启动、引导、审批和审查已连接主机上的 Codex 工作。

### 计算机使用

让 Codex 使用 macOS 应用处理 GUI 任务、浏览器流程和原生应用测试。

### 审查并发布变更

检查差异、处理 PR 反馈、暂存文件、提交和推送。

### 终端与操作

在每个线程中运行命令，启动可重复的项目操作。

### 应用内浏览器

打开渲染页面、发表评论，或让 Codex 操作本地浏览器流程。

![Codex 应用内浏览器](/images/codex/app/in-app-browser-light.webp)

### Chrome 扩展

添加 Chrome 插件，让 Codex 可以使用 Chrome 处理已登录的浏览器任务，同时由你管理网站审批。

### 图像生成

在处理周围代码和资源的同时，在线程中生成或编辑图像。

### 自动化

安排定时任务，或唤醒同一线程进行持续检查。

![Codex 自动化](/images/codex/app/codex-automations-light.webp)

### 技能

在桌面应用、CLI 和 IDE 扩展之间复用指令和工作流程。

### 侧边栏与产物

跟踪计划、源文件、任务摘要和生成的文件预览。

### 插件

连接应用、技能和 MCP 服务器，扩展 Codex 的能力。

### IDE 扩展同步

在桌面应用和 IDE 会话之间共享自动上下文和活动线程。
