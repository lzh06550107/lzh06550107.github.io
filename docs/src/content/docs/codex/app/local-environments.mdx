# 本地环境

> 为工作树配置设置步骤，以及为项目定义常用操作

本地环境允许你为工作树配置设置步骤，也可以为项目定义常用操作。

你可以在 **Codex 应用设置**面板中配置本地环境。你可以将生成的文件提交到项目的 Git 仓库中，以便与其他人共享。

Codex 将此配置存储在项目根目录下的 `.codex` 文件夹中。如果你的仓库包含多个项目，请打开包含共享 `.codex` 文件夹的项目目录。

## 设置脚本

由于工作树运行的目录与你的本地任务不同，你的项目可能尚未完全设置，并且可能缺少未提交到仓库的依赖项或文件。当 Codex 在新线程开始时创建工作树时，设置脚本会自动运行。

使用此脚本运行配置环境所需的任何命令，例如安装依赖项或运行构建流程。

例如，对于一个 TypeScript 项目，你可能希望安装依赖项并使用设置脚本进行初始构建：

```bash
npm install
npm run build
```

如果你的设置是平台特定的，可以为 macOS、Windows 或 Linux 定义设置脚本以覆盖默认脚本。

## 操作（Actions）

使用操作来定义常见任务，例如启动应用的开发服务器或运行测试套件。这些操作会显示在 Codex 应用的顶部栏中，以便快速访问。操作将在应用的内置终端中运行。

操作有助于避免你重复输入常见命令，例如触发项目构建或启动开发服务器。对于一次性快速调试，你可以直接使用内置终端。

例如，对于一个 Node.js 项目，你可以创建一个包含以下脚本的"运行"操作：

```bash
npm start
```

如果你的操作命令是平台特定的，可以为 macOS、Windows 和 Linux 定义平台特定的脚本。

要标识你的操作，请为每个操作选择一个关联的图标。
