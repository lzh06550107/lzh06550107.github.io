# 模型上下文协议 (MCP)

> 让 Codex 访问第三方工具和上下文

模型上下文协议（MCP）将模型连接到工具和上下文。用于让 Codex 访问第三方文档，或与浏览器、Figma 等开发者工具交互。

Codex 在 CLI 和 IDE 扩展中均支持 MCP 服务器。

## 支持的 MCP 特性

| 类型 | 说明 |
| --- | --- |
| **STDIO 服务器** | 作为本地进程运行（由命令启动），支持环境变量 |
| **Streamable HTTP 服务器** | 通过地址访问，支持 Bearer Token 和 OAuth 认证 |

## 连接 Codex 到 MCP 服务器

Codex 将 MCP 配置存储在 `config.toml` 中。默认位置为 `~/.codex/config.toml`，也可以将 MCP 服务器限定到项目级别（`.codex/config.toml`）。

CLI 和 IDE 扩展共享此配置。配置完成后可在两者间切换，无需重新设置。

<Tabs>
  <TabItem label="使用 CLI 配置">

    ### 添加 MCP 服务器
    ```bash
    codex mcp add <server-name> --env VAR1=VALUE1 -- <stdio server-command>
    ```

    ### 示例：添加 Context7
    ```bash
    codex mcp add context7 -- npx -y @upstash/context7-mcp
    ```

    ### 其他命令
    ```bash
    codex mcp --help
    ```

    在 TUI 中使用 `/mcp` 查看活动的 MCP 服务器。
  </TabItem>

  <TabItem label="编辑 config.toml">

    ### STDIO 服务器示例
    ```toml
    [mcp_servers.context7]
    command = "npx"
    args = ["-y", "@upstash/context7-mcp"]
    env_vars = ["LOCAL_TOKEN"]

    [mcp_servers.context7.env]
    MY_ENV_VAR = "MY_ENV_VALUE"
    ```

    ### Streamable HTTP 服务器示例
    ```toml
    [mcp_servers.figma]
    url = "https://mcp.figma.com/mcp"
    bearer_token_env_var = "FIGMA_OAUTH_TOKEN"
    http_headers = { "X-Figma-Region" = "us-east-1" }
    ```

    ### 高级配置
    ```toml
    [mcp_servers.chrome_devtools]
    url = "http://localhost:3000/mcp"
    enabled_tools = ["open", "screenshot"]
    disabled_tools = ["screenshot"]
    default_tools_approval_mode = "prompt"
    startup_timeout_sec = 20
    tool_timeout_sec = 45
    enabled = true

    [mcp_servers.chrome_devtools.tools.open]
    approval_mode = "approve"
    ```
  </TabItem>
</Tabs>

### MCP 配置选项

| 选项 | 说明 |
| --- | --- |
| `command` | （STDIO 必填）启动服务器的命令 |
| `args` | 传递给服务器的参数 |
| `env` / `env_vars` | 设置或允许转发的环境变量 |
| `url` | （HTTP 必填）服务器地址 |
| `bearer_token_env_var` | Bearer Token 的环境变量名 |
| `startup_timeout_sec` | 服务器启动超时（默认 10 秒） |
| `tool_timeout_sec` | 工具运行超时（默认 60 秒） |
| `enabled` | 设为 `false` 禁用而不删除 |
| `required` | 设为 `true` 使启动失败时终止 |
| `enabled_tools` / `disabled_tools` | 工具允许/禁止列表 |
| `default_tools_approval_mode` | 默认审批模式：`auto`、`prompt`、`approve` |
| `tools.<tool>.approval_mode` | 每个工具的审批模式覆盖 |

## 实用的 MCP 服务器示例

| 服务器 | 用途 |
| --- | --- |
| **OpenAI Docs MCP** | 搜索和阅读 OpenAI 开发者文档 |
| **Context7** | 连接最新开发者文档 |
| **Figma** | 访问 Figma 设计稿 |
| **Playwright** | 使用 Playwright 控制和检查浏览器 |
| **Chrome DevTools** | 控制和检查 Chrome |
| **Sentry** | 访问 Sentry 日志 |
| **GitHub** | 管理 GitHub 仓库（PR、issues 等） |
