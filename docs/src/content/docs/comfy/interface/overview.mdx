# ComfyUI 界面概览

可视化界面是目前大多数用户使用 ComfyUI 来调用 ComfyUI Server 进行媒体资源生成的方式。它提供了一个可供用户操作和组织工作流的可视化界面，用于组织和调试工作流，并生成令人惊叹的作品。

在本篇我们将粗略介绍 ComfyUI 的界面以及各个部分的功能。在后续章节中，会详细介绍各个部分的功能和使用方法。

通常，当你启动 ComfyUI 后，你会看到一个包含画布、侧边栏、节点和执行按钮的基础界面。
