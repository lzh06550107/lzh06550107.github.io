# 如何在不同系统上手动安装 ComfyUI

对于 ComfyUI 的安装，主要分为几个步骤：

1. 创建一个虚拟环境（避免污染系统级 Python 环境）
2. 克隆 ComfyUI 代码仓库
3. 安装依赖
4. 启动 ComfyUI
