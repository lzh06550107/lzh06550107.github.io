## 2.1.148

*2026 年 5 月 22 日*

- 修复了部分用户的 Bash 工具在每个命令上都返回退出码 `127` 的问题（这是在 `2.1.147` 中引入的回归）。

## 2.1.147

*2026 年 5 月 21 日*

- 已固定的后台会话（在 `claude agents` 中按 `Ctrl+T`）现在在空闲时仍会保持存活；为应用 Claude Code 更新时会原地重启；只有在内存压力下，且在非固定会话之后，才会被回收。
- 将 `/simplify` 重命名为 `/code-review`。它现在会按你选择的工作强度级别报告正确性问题（例如 `/code-review high`）；传入 `--comment` 可将发现作为 GitHub PR 行内评论发布。旧的“清理并修复”行为已移除。
- 改进自动更新器：现在会重试临时网络故障；失败时会报告具体错误类别和操作系统错误码；更新失败时还会显示当前版本。
- 改进大文件编辑时的 diff 渲染性能。
- Prompt 历史记录不再记录连续重复项——用方向上键调出某个提示并再次提交时，不会再新增一条相同记录。
- 修复企业登录限制（`forceLoginOrgUUID` 和 `forceLoginMethod` 托管设置）未对第三方提供商和 API Key 会话生效的问题。
- 修复 `!` 命令输出中的 `&` 被显示为 `&amp;` 的问题，这会导致在无头机器上从 `gcloud auth login` 等命令中复制粘贴 URL 失败。
- 修复在 headless/SDK 模式下，未知斜杠命令静默无效的问题——现在会显示错误信息。
- 修复 `/help` 在小终端、非全屏模式下只显示每页一个命令并出现损坏标签头的问题。
- 修复 shell 快照会丢弃名称以单个下划线开头的用户函数，导致引用它们的别名失效的问题。
- 修复插件代理在 `tools` frontmatter 中声明多个 `Agent(...)` 类型时，只保留最后一个条目的问题。
- 修复诸如 `PowerShell(git push*)` 这样的 hook `if` 条件永远不匹配的问题——此前只有 `PowerShell(*)` 有效。
- 修复 PowerShell 工具会丢失依赖默认格式化器的命令输出的问题。
- 修复 Windows 上为 PowerShell 脚本调用选择 “Yes, and don’t ask again” 后，写入的规则无法在后续运行中实际匹配的问题。
- 修复在 Windows 上通过 winget 或 Microsoft Store 安装 `pwsh` 时，PowerShell 工具会以退出码 1 失败的问题。
- 修复 `/effort` 打开时滑块默认落在错误级别的问题——现在会从你当前的 effort 级别开始。
- 修复分页获取 MCP 服务器时会丢失第 1 页之后的资源、模板和 prompts 的问题。
- 修复在 Windows Terminal 中，附加到后台会话时全屏界面流式输出会闪烁的问题。
- 修复 Windows 上删除后台任务 worktree 时会沿着 NTFS junction 跟入主仓库的问题。
- 修复 `/background` 拒绝那些唯一输入只是 skill 或自定义斜杠命令的会话的问题。
- 修复自动模式抑制 `AskUserQuestion` 的问题：当用户或 skill 明确依赖它时，现在不会再被抑制；自动模式分类器现在也会把用户回答视为意图信号。
- 修复 `/theme` 中 “New custom theme” 和颜色编辑器对话框不能响应 `Esc` 的问题。
- 修复通过 Agent SDK 运行时，流式会话结束时出现的未捕获异常。
- 修复 Windows 上等待滚动稳定时极少发生的卡死。
- 修复在 Windows 上，后台会话结果包含宽字符（CJK）时，agent view 列表会显示陈旧或重复行的问题。
- 修复粘贴文本会以不可读的 `[Pasted text #N]` 占位符发送给代理，而不是实际文本内容的问题。
- 修复插件清单列出与默认目录重叠路径时，`claude plugin details` 和 `/plugin` 中的插件组件计数会被重复计算的问题。
- 修复后台化会话会再次询问你已经用 “don’t ask again” 授权过的工具权限的问题。
- 修复 GNOME Terminal 中右键粘贴和中键粘贴无效的问题。
- 修复 `CLAUDE_CODE_SUBAGENT_MODEL` 无法应用到代理团队所派生 teammate 进程的问题。
- 修复后面带 Tab 或换行的斜杠命令会被识别为未知命令的问题。
- 修复 `/plugin`、`/status`、`/mobile`、`/sandbox` 和 `/permissions` 菜单中的多处间距与布局问题。
- 修复被剥离的图片会反复提示模型重新读取已不存在媒体的问题。

## 2.1.145

*2026 年 5 月 19 日*

- 新增 `claude agents --json`，可将活动中的 Claude 会话以 JSON 格式列出，便于脚本化使用（例如 `tmux-resurrect`、状态栏、会话选择器）。
- 为 `claude_code.tool` OpenTelemetry spans 添加 `agent_id` 与 `parent_agent_id` 属性，并修复 trace 父子关系，使后台 subagent spans 会嵌套在分发它们的 Agent tool span 下。
- 状态行 JSON 输入现在在检测到时会包含 GitHub 仓库与 PR 信息。
- `/plugin` 的 Discover 和 Browse 界面现在会在安装前显示插件的命令、agents、skills、hooks 以及 MCP/LSP 服务器。
- `claude agents` 终端标签标题现在会显示等待输入计数，因此即使窗口在后台，你也能知道代理何时需要关注。
- 全屏模式下，斜杠命令与 `@` 提及建议列表现在支持鼠标悬停和点击。
- `Stop` 和 `SubagentStop` hook 输入现在包含 `background_tasks` 和 `session_crons` 字段。
- 修复 Bash 命令中对非白名单环境变量进行裸变量赋值时会被自动批准的权限提示绕过问题。
- 修复 MCP prompt 斜杠命令在缺少必填参数时直接展示原始服务端校验错误的问题——现在会指出缺失参数并显示预期用法。
- 修复终端在调整大小或重新获得焦点后，spinner 和已用时间显示会冻结直到按键的问题。
- 修复跨项目 resume 提示在默认 Windows PowerShell 5.1 中失效的问题——Windows 现在使用 `;` 作为命令分隔符。
- 修复 agent view 回复面板中的语音按住说话失效问题。
- 修复一次性创建多个任务时任务列表顺序随机的问题。
- 修复已经安装 marketplace 后，仍显示陈旧的 “Failed to install Anthropic marketplace” 横幅的问题。
- 修复在运行 `gh pr create` 等改变 PR 状态的命令后，页脚中的 PR 徽章不能立即更新的问题。
- 修复 Agent Teams 中具有非 ASCII 名称的 teammate 会因无效 header 编码导致所有 API 调用失败的问题。
- 修复 `/review` 使用已弃用的 `projectCards` GraphQL 查询，在启用了 Classic Projects 的仓库中报错的问题。
- 修复 `claude plugin validate` 不会标记指向文件而非目录的 `skills:` 条目——现在会报错并建议使用父目录。
- 修复使用 `context: fork` 的 skill 可能反复重新调用自身而不是执行的死循环问题。
- 改进 Read 工具：当整文件读取超过 token 限制时，不再直接报错，而是返回截断后的第一页并附带 “PARTIAL view” 提示。

## 2.1.144

*2026 年 5 月 19 日*

- `/resume` 现已支持后台会话——通过 `claude --bg` 或 agent view 启动的会话现在会和交互式会话一起显示，并以 `bg` 标记。
- 后台 subagent 完成通知现在会显示耗时（例如 `Agent completed · 3h 2m 5s`）。
- `/plugin` 的 browse 和 discover 面板现在会显示插件最近更新时间。
- `/model` 现在只会修改当前会话的模型；在模型选择器中按 `d` 可为新会话设置默认值。
- 将界面文案中的 “extra usage” 重命名为 “usage credits”；`/extra-usage` 现为 `/usage-credits`（旧名称仍可用）。
- 修复在 `api.anthropic.com` 不可达时（如 captive portal、防火墙、VPN 问题）启动可能卡住长达 75 秒的问题——旁路 API 调用现在 15 秒超时。
- 修复错过窗口 resize 事件后终端输出乱码的问题（例如拖动 VS Code 分屏分隔条）——现在会在下一帧自愈，而不需要手动 `Ctrl+L`。
- 修复长时间会话中逐渐出现的终端渲染损坏（陈旧/乱码字符）问题，此前只能通过调整窗口大小或重启清除。
- 通过减少 spinner 动画颜色数量，降低 VS Code 中终端渲染异常。
- 修复 macOS 上后台会话在受 Full Disk Access 保护的目录下崩溃并提示 `exit 1 before init` 的问题。

## 2.1.143

*2026 年 5 月 15 日*

- 新增插件依赖强制校验：当其他已启用插件依赖目标插件时，`claude plugin disable` 现在会拒绝执行，并给出可复制粘贴的禁用链提示；`claude plugin enable` 会强制启用传递依赖。
- 在 `/plugin` marketplace 浏览面板中新增投影上下文成本（每轮/每次调用 token 估算）。
- 新增 `worktree.bgIsolation: "none"` 设置，可让后台会话直接编辑工作副本而无需 `EnterWorktree`，适用于不方便使用 worktree 的仓库。
- PowerShell 工具现在会传入 `-ExecutionPolicy Bypass`。可通过 `CLAUDE_CODE_POWERSHELL_RESPECT_EXECUTION_POLICY=1` 关闭。
- 后台会话现在会保留你在唤醒后设置的模型和 effort 级别。
- 修复会读取扩展名与实际内容不匹配的文件（例如把 HTML 保存成 `.png`）时，会造成会话不可恢复的问题——现在会回退为文本读取。
- 减少搜索时的误报工具错误：`head`/`tail` 文件视图现在可满足“编辑前先读取”的检查；`egrep`、`fgrep`、`git grep`、`git diff` 返回 “no matches”（退出码 1）时不再被视作命令失败。
- 修复在进入 worktree 后或某些后台会话中，`/branch` 报 `No conversation to branch` 的问题。
- 修复在 `AskUserQuestion` 的备注字段中按 `Escape` 会中止整轮，而不是返回答案选择的问题。
- 修复通过 IDE 模型选择器或启动后 `applyFlagSettings` 更改模型时，实际未生效的问题。
- 恢复的会话现在会保留原本使用的模型，而不是继承其他会话的 `/model` 选择。
- 修复 Bedrock 和 Vertex 用户无法在 `/model` 选择器中选中 `Opus (1M context)` 的回归问题（始于 `v2.1.129`）。
- 修复启用了 `forceLoginMethod` 与 `forceLoginOrgUUID` 时，远程会话登录会报 `Can’t access this organization` 的问题。
- 修复带分页 `tools/list` 响应的 MCP 服务器只返回第一页、静默丢弃工具的问题。
- 修复不受支持 MIME 类型（如 SVG）的 MCP 图片会破坏对话的问题——现在会保存到磁盘并在工具结果中引用。
- 修复在 skill 目录内运行构建时会耗尽文件描述符的问题——非 `.md` 文件不再触发 skill 重载。
- 修复会话标题由插件监控输出生成，而不是由用户首条提示生成的问题。
- 修复 Skill 工具在 headless 模式下权限错误的问题（回归于 `v2.1.141`）。
- 修复你自己设置中启用的插件在新机器首次加载后显示 “not cached” 错误的问题；而仅由项目 `.claude/settings.json` 启用的插件，现在会显示可执行的 `claude plugin install` 提示。

- 修复 Windows 上附加到后台会话时滚动失效的问题——现在 `PgUp/PgDn`、鼠标滚轮和 `Ctrl+O` transcript 导航都可使用。
- 修复在附加到后台会话时关闭终端会崩溃的问题。
- 修复 Windows 上在 `claude agents` 中按左箭头后列表失去键盘响应的问题。
- 修复 Windows Terminal 中包含 CJK 内容时，切换 pane 左边缘会出现鬼影字符的问题。
- `/bg` 和左箭头 detatch 现在会保留通过 `/add-dir` 添加的目录。
- 修复 detatch 一个已在原地编辑的会话后，`Edit/Write` 仍会报 `background session hasn't isolated its changes yet` 的问题。
- 修复 `claude respawn <id>` 针对已停止后台会话时，状态显示为 `stopped` 而不是 `running` 的问题。
- 修复 `/resume` 选择器不显示从后台会话 fork 出来的会话的问题。

- 修复 subagent 产生的后台 Bash 任务在进程结束后仍在 SDK 任务面板中显示为 `Running` 的问题。

- `claude agents` / `--bg` 拒绝消息现在会指出具体原因（如非 TTY、环境变量或设置），而不是泛化错误。
- `claude --bg --name <label>` 现在会在启动确认中回显名称。
- 在 `claude agents` 中用 `Ctrl+R` 重命名后台会话后，附加会话顶部横幅会立即更新。

## 2.1.142

*2026 年 5 月 14 日*

- 为 `claude agents` 新增参数：`--add-dir`、`--settings`、`--mcp-config`、`--plugin-dir`、`--permission-mode`、`--model`、`--effort` 和 `--dangerously-skip-permissions`，可用于配置派发的后台会话。
- Fast mode 默认改用 Opus 4.7（此前为 Opus 4.6）。如需固定为 Opus 4.6，可设置 `CLAUDE_CODE_OPUS_4_6_FAST_MODE_OVERRIDE=1`。
- 现在插件如果在根目录放置了 `SKILL.md` 且没有 `skills/` 子目录，也会被识别为一个 skill。
- `/plugin` 详情面板和 `claude plugin details` 现在会显示插件提供的 LSP 服务器。
- `/web-setup` 在替换已有 GitHub App 连接前会先给出警告。
- 修复 `MCP_TOOL_TIMEOUT` 不会提升远程 HTTP / SSE MCP 服务器单次请求超时的问题，此前无论配置如何都被限制为 60 秒。
- 修复后台会话无法识别已有 git worktree、导致 `Edit` 被阻止而 `EnterWorktree` 又拒绝创建重复 worktree 的问题。
- 修复 macOS 休眠/唤醒后后台会话消失、daemon 重连失败的问题——daemon 现在会检测时钟跳变，而不是把它误当成真实空闲时间。
- 修复二进制升级后（例如 `brew upgrade`）daemon 不能正常退出，导致派发代理在被删除的路径上 crash-loop 的问题。
- 修复连接了 Claude-in-Chrome 扩展但没有共享标签页时，后台代理 crash-loop 的问题。
- 修复附加到 `claude agents` 会话时点击链接失效的问题——后台 worker 的无头浏览器 shim 在附加状态下不再启用。
- 修复 `claude agents` 中 “v to open in editor” 使用 daemon 默认编辑器而不是当前 shell 的 `$EDITOR/$VISUAL` 的问题。
- 修复 Windows 上当工作目录位于网络驱动器时 `claude agents` 会死锁的问题；现在启动期间 `Ctrl+C` 可正常工作。
- 修复从 Apple Terminal 或其他仅支持 256 色的终端附加后台会话时，背景色渗漏的问题。
- 修复 `claude --bg --dangerously-skip-permissions` 在 retire/wake 后不持久的问题。
- 修复当首条消息是链接时，会话标题被生成为 URL 的问题。

- 修复 Read 工具在 `offset` 以带空格或 `+` 前缀字符串传入时校验失败的问题。

- 插件现在会在默认组件目录（如 `commands/`）因 `plugin.json` 设置了同名键而被静默忽略时发出警告；该警告会显示在 `/doctor`、`claude plugin list` 和 `/plugin` 中。

## 2.1.139

*2026 年 5 月 11 日*
