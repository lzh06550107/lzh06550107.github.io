在当前应用中通过 TypeScript SDK 安装 Stagehand。

:::tip[提示]
我们建议使用 **Node.js** 运行时来执行 Stagehand 脚本。

**现已支持 Bun**，前提是你**不要**将 Stagehand 与 Playwright 集成。Playwright 与 Bun 不兼容。
:::

  ## 安装依赖

  <Tabs>
    <TabItem label="npm">

    ```bash
    npm install @browserbasehq/stagehand
    ```
    </TabItem>

    <TabItem label="pnpm">

    ```bash
    pnpm add @browserbasehq/stagehand
    ```
    </TabItem>

    <TabItem label="yarn">

    ```bash
    yarn add @browserbasehq/stagehand
    ```
    </TabItem>

    <TabItem label="bun">

    ```bash
    bun add @browserbasehq/stagehand
    ```

  :::tip[提示]
  如果你打算在本地运行，则需要在你的机器上安装 [Chrome](https://www.google.com/chrome/)。如果你使用云浏览器会话，则可跳过这一步。
  :::

  ## 配置环境

  设置环境变量（或者通过你的框架使用 `.env`）：

  ```bash
  OPENAI_API_KEY=your_api_key
  BROWSERBASE_API_KEY=your_api_key
  ```

  :::note[说明]
  Stagehand **不会自动加载** `.env` 文件。

  如果你使用 `.env` 文件，请在你自己的应用代码中安装并初始化 `dotenv`：

  ```bash
  npm install dotenv
  ```

  ```ts
  import dotenv from "dotenv";
  dotenv.config({ path: ".env" });
  ```
  :::

  ## 在你的代码库中使用

  在需要浏览器自动化的地方引入 Stagehand。

  ```ts
  import dotenv from "dotenv";
  import { Stagehand } from "@browserbasehq/stagehand";
  import { z } from "zod";

  dotenv.config({ path: ".env" });  // 如有需要

  async function main() {
    const stagehand = new Stagehand({
      env: "BROWSERBASE"
    });

    await stagehand.init();
    const page = stagehand.context.pages()[0];

    await page.goto("https://example.com");

    // 在页面上执行操作
    await stagehand.act("Click the learn more button");

    // 提取结构化数据
    const description = await stagehand.extract("extract the description", z.string());

    console.log(description);
    await stagehand.close();
  }

  main().catch((err) => {
    console.error(err);
    process.exit(1);
  });
  ```
