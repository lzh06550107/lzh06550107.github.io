# Next.js + Vercel

> 构建并部署基于 Stagehand 的 Next.js 应用到 Vercel

## 概览

Stagehand + Next.js Quickstart 是一个可用于生产环境的模板，它将 Stagehand 的 AI 浏览器自动化能力与现代 Next.js 应用结合起来，并支持在 Vercel 上一键部署。

## 要求

- **Node 18+** 本地环境
- **模型密钥**：OpenAI 或 Anthropic（也可接入自定义客户端）
- **Browserbase Key**：云浏览器需要 `BROWSERBASE_API_KEY`

:::tip[提示]
Vercel 上无法使用本地 Playwright 浏览器。部署时请将 Stagehand 配置为 Browserbase。
:::
