# LangChain JS 简介

> 将 Stagehand 与 LangChain JS 集成，实现智能网页自动化

## 概览

本指南将向你展示如何将 Stagehand 与 LangChain JS 结合使用，以创建能够自动化网页交互的智能代理。阅读完本指南后，你将了解如何：

- 使用 LangChain JS 配置 `StagehandToolkit`
- 创建能够导航并与网站交互的代理
- 使用自然语言指令提取结构化数据
- 使用 LangGraph 构建复杂的自动化工作流

## 适用场景

当你需要具备高级推理能力的智能网页自动化时，LangChain JS 集成非常适合以下场景：

- **AI 驱动的研究**：创建可跨多个网站搜集信息并综合结论的代理
- **动态表单填写**：基于上下文要求自动填写复杂表单
- **数据提取工作流**：通过智能导航从多个来源提取并转换数据
- **多步骤网页流程**：执行需要决策与自适应能力的复杂浏览器工作流
