# Browserbase MCP 服务器

> 通过与 Stagehand 集成的模型上下文协议（MCP）实现 AI 驱动的浏览器自动化

## 概览

Browserbase MCP 服务器通过模型上下文协议（MCP）为 MCP 客户端带来强大的浏览器自动化能力。该集成构建于 [Stagehand](https://docs.stagehand.dev/) 之上，能够使用自然语言命令提供 AI 驱动的 Web 自动化。

:::note[说明]
托管的 [Streamable HTTP](https://modelcontextprotocol.io/specification/2025-03-26/basic/transports#streamable-http) 端点由 Browserbase 基础设施提供服务。
你也可以通过 STDIO 在本地运行 MCP 服务器，但对于大多数用户，我们推荐使用托管的 [Streamable HTTP](https://modelcontextprotocol.io/specification/2025-03-26/basic/transports#streamable-http) 端点。
:::

## 快速开始

1. **安装 MCP 服务器**  
   根据你的需求，在托管的 [Streamable HTTP](https://modelcontextprotocol.io/specification/2025-03-26/basic/transports#streamable-http)（推荐）和本地 STDIO 之间进行选择。

2. **配置身份验证**  
   在 MCP 配置中设置你的 Browserbase API 凭据。你可以在 [Browserbase Dashboard](https://www.browserbase.com/overview) 获取 API Key。

3. **开始自动化**  
   通过你的 MCP 客户端使用自然语言命令开始控制浏览器。

:::tip[提示]
准备好开始了吗？请查看[设置指南](https://docs.stagehand.dev/v3/integrations/mcp/setup)。
:::
