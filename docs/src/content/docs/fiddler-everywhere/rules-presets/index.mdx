# 规则预设

本节对应官方菜单 **Rules Presets**。它介绍可复用的规则预设，用于快速完成阻止、允许、过滤、映射、修改和 UI 相关流量操作。

## 菜单页面顺序

1. **Block and Allow Lists**：阻止列表和允许列表。
2. **Filters**：过滤器。
3. **Map Traffic**：映射流量。
4. **Modify Traffic**：修改流量。
5. **Tooling**：工具。
6. **UI Modifications**：UI 修改。
7. **Index**：规则预设入口页。

## 功能说明

规则预设帮助用户快速套用常见调试逻辑，而不必从零创建规则。你可以用它们阻止特定请求、允许特定流量、映射响应、修改请求或响应内容，并通过预设组合复现常见调试场景。
