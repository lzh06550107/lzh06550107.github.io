# Agent 工具

本节对应官方菜单 **Agent Tools**。它介绍 Fiddler Everywhere 面向 AI 编码助手和自动化代理提供的工具，包括 MCP Server、Prompt Library、Agent Skills 和自定义 Skills。

## 菜单页面顺序

1. **Agent Skills**：Agent 技能。
2. **Creating Custom Skills**：创建自定义技能。
3. **Fiddler MCP Server**：Fiddler MCP 服务器。
4. **Prompt Library**：提示词库。

## 作用

Agent Tools 的目标是让 AI 编码助手能够直接读取、分析和操作 Fiddler 捕获的真实网络流量，而不是只根据静态代码猜测接口行为。通过 MCP Server，支持的编码工具可以查询会话、应用过滤器、读取请求响应详情，并结合 Fiddler 的调试能力辅助开发。
