# 用户界面

本节对应官方菜单 **User Interface**。它介绍 Fiddler Everywhere 的界面布局、设置、快捷键和状态栏。

## 菜单页面顺序

1. **Settings**：设置。
2. **Index**：用户界面入口。
3. **Keyboard Shortcuts**：键盘快捷键。
4. **Status Bar**：状态栏。

## 功能说明

Fiddler Everywhere 提供现代、直观的界面，包括流量列表、会话详情、规则、过滤器、Composer、协作相关入口以及设置菜单。用户可以通过快捷键、主题、布局和状态栏信息提高调试效率。
