# 安全

本节对应官方菜单 **Security**。它介绍 Fiddler Everywhere 的安全基础、数据清理、安全亮点和 TLS 版本细节。

## 菜单页面顺序

1. **Fiddler Everywhere Fundamentals**：Fiddler Everywhere 基础。
2. **Sanitization**：数据清理。
3. **Security Highlights**：安全亮点。
4. **TLS Version Specifics**：TLS 版本细节。

## 说明

Fiddler Everywhere 作为本地调试代理，会涉及 HTTPS 解密、证书信任、会话数据保存与共享等敏感操作。安全章节用于说明这些能力的工作边界、证书与 TLS 行为、数据清理方式，以及在团队协作和问题排查中应注意的安全事项。
