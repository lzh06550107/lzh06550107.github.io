# 调试助手

本节对应官方菜单 **Debugging Assistant**。它介绍 Fiddler Everywhere 的调试助手能力，用于辅助分析捕获的网络会话并定位问题。

## 菜单页面顺序

1. **Fiddler Assistant**：Fiddler 助手。

## 功能说明

调试助手用于围绕捕获的网络流量提供分析支持。它可以帮助用户更快理解请求失败、响应异常、认证问题、证书问题或接口行为差异等现象。
