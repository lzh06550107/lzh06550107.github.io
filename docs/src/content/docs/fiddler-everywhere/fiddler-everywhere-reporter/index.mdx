# Fiddler Everywhere Reporter

本节对应官方菜单 **Fiddler Everywhere Reporter**。Reporter 是用于捕获和共享 Web 流量日志的轻量工具，适合让非技术用户收集网络问题相关日志并交给技术团队排查。

## 菜单页面顺序

1. **Features**：功能。
2. **Overview**：概览。

## 功能说明

Fiddler Everywhere Reporter 更偏向“日志采集和交付”场景，而不是完整的开发调试工具。它通常用于客户支持、故障排查和复现问题：用户捕获流量日志后，可以把日志发给开发、测试或支持团队分析。
