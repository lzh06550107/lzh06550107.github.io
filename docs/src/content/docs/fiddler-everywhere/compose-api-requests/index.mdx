# 编写 API 请求

本节对应官方菜单 **Compose API Requests**。Fiddler Everywhere 提供 API Composer，用于创建、修改、执行、保存和组织 API 请求。

## 菜单页面顺序

1. **API Requests Collections**：API 请求集合。
2. **API Requests Composer**：API 请求编写器。

## 功能说明

API Composer 可用于测试 REST 和 SOAP API。你可以创建请求、设置方法、URL、Header、Body 和认证相关内容，然后直接发送请求并查看响应。编写好的请求还可以保存和共享，用于开发、调试和回归测试。
