# 捕获流量

本节对应官方菜单 **Capture Traffic**。它介绍 Fiddler Everywhere 支持的多种流量捕获方式，包括系统代理捕获、独立浏览器捕获、终端捕获、网络捕获、移动设备捕获、远程 PC 捕获和反向代理。

## 菜单页面顺序

1. **Advanced Capturing Options**：高级捕获选项。
2. **Capture Browser Traffic**：捕获浏览器流量。
3. **Capture from Android**：从 Android 捕获流量。
4. **Capture from iOS**：从 iOS 捕获流量。
5. **Capture from Remote PC**：从远程 PC 捕获流量。
6. **Capture Network Traffic**：捕获网络流量。
7. **Capture System Traffic**：捕获系统流量。
8. **Capturing Modes**：捕获模式概览。
9. **Capturing Traffic from Terminal**：从终端捕获流量。
10. **Reverse Proxy**：反向代理。

## 捕获模式概览

Fiddler Everywhere 是一个综合性的 Web 调试代理，可以捕获 HTTP(S)、WebSocket、Server-Sent Events（SSE）和 gRPC 流量。作为本地转发 TLS 代理，它可以拦截本地安装应用程序以及网络中远程设备产生的流量。

## 常见使用方式

- 使用 **System Proxy** 捕获遵循操作系统代理设置的应用流量。
- 使用 **Browser Capturing** 启动独立、沙盒化的浏览器捕获会话。
- 使用 **Terminal Capturing** 捕获从内置终端启动的命令行程序流量。
- 使用 **Network Capture** 在更低层级捕获网络适配器上的出站 TCP 流量。
- 使用 Android、iOS 或远程 PC 配置，让移动设备或其他设备的流量经过 Fiddler Everywhere。
