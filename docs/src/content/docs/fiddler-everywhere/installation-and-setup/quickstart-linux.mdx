本文介绍如何在 Linux 上安装并开始使用 Fiddler Everywhere。整体流程包括：

1. 完成安装和基础配置。
2. 创建并登录 Fiddler/Telerik 账号。
3. 捕获、检查和修改网络流量。

## 前置条件

在 Linux 上使用 Fiddler Everywhere 前，需要确认以下条件：

- 使用 Ubuntu 22+ x64。
- 预留约 400 MB 可用磁盘空间。
- 使用具备管理员权限的账号，因为捕获和解密 HTTPS 流量时会用到相关权限。
- 保持可用的互联网连接，并允许访问 Telerik、GetFiddler、相关下载服务和 Cloudflare 验证服务。

```text
https://*.telerik.com/
https://*.getfiddler.com/
https://fiddler-backend-production.s3-accelerate.amazonaws.com
https://challenges.cloudflare.com
```

- 确保 Fiddler Everywhere 使用的代理端口未被防火墙或安全工具限制。默认端口是 `8866`，也可以在设置中的连接选项里修改监听端口。

:::tip[网络访问提示]
Telerik 登录页面会通过不同 CDN 加载界面组件、样式和 Cookie 相关资源。如果网络访问受限，登录或注册页面可能无法正常加载。
:::

## 步骤 1：安装 Fiddler Everywhere

首先在 Linux 机器上下载并安装最新版 Fiddler Everywhere。

下载完成后，安装包通常需要先设置为可执行文件，再启动安装。你可以通过命令行或发行版图形界面完成该操作。

### 通过命令行设置可执行权限

1. 打开终端。
2. 进入安装文件所在目录。
3. 执行以下命令，将 AppImage 文件设为可执行：

```bash
sudo chmod +x filename.appimage
```

如果当前登录用户就是下载安装文件的用户，某些环境下可以不使用 `sudo`。

4. 如果系统提示输入用户名或密码，按提示输入后按 `Enter`。

### 通过图形界面设置可执行权限

也可以在桌面环境的文件属性或权限设置中，把安装文件标记为可执行。常见桌面环境包括 Gnome、Cinnamon 和 KDE。

## Ubuntu 24.04 注意事项

Ubuntu 24.04 上，部分基于 Electron 的应用可能遇到 AppImage 无法设置为可执行或无法正常启动的问题。若按上面的步骤仍无法运行安装文件，可以先安装 AppImage 所需依赖：

```bash
sudo apt install libfuse2
```

如果安装依赖后应用仍无法启动，可以从终端启动并查看错误输出。若出现 SUID sandbox helper 相关错误，可尝试在终端启动时追加 `--no-sandbox` 参数。

## 步骤 2：创建 Fiddler 账号

启动 Fiddler Everywhere 后，选择登录或创建账号入口，并创建统一的 Telerik 账号。

可选方式包括：

- 使用邮箱和密码注册。
- 使用 Google 登录。
- 企业订阅场景下使用 SSO 登录。

注册过程中需要填写页面要求的信息，并通过邮箱确认完成账号激活。激活后回到 Fiddler Everywhere，可以选择开始免费试用，或购买订阅计划。

登录成功后，首页面板会显示你的个人信息和许可证信息。

## 步骤 3：处理捕获到的流量

账号准备完成后，就可以使用 Fiddler Everywhere 捕获、检查、保存、共享、导入、导出、模拟和修改 HTTPS 流量。

常见操作流程如下：

1. 选择合适的捕获模式，开始捕获 HTTPS 流量。
2. 如需捕获并解密安全 HTTPS 流量，需要安装并信任 Fiddler 的 CA 证书。
3. 在 Linux 上，也可以将 Fiddler CA 证书安装到第三方证书存储中，例如 Firefox 的证书存储，然后只捕获该应用的流量。
4. 检查捕获到的数据。
5. 根据需要保存、共享或导出捕获的 HTTPS 流量。
6. 通过 Composer 修改会话或构造请求。
7. 通过 Rules 规则能力模拟客户端或服务端行为。

:::tip[Rules 的用途]
Rules 是 Fiddler Everywhere 中比较高级的能力。它可以在不修改客户端或服务端应用的情况下，对进入的流量执行规则，从而模拟客户端或服务端行为。
:::

## 下一步

完成 Linux 初始配置后，可以继续学习以下主题：

- Fiddler Everywhere 的捕获选项。
- 安装并信任 Fiddler CA 证书，以解密 HTTPS 流量。
- 与协作者共享捕获的会话。
- 创建 API 请求。
- 将 API 请求组织到集合中。
- 模拟服务端响应。
- 在 Fedora、CentOS 或 RedHat 上配置 Fiddler Everywhere。
- 在 XFCE 上配置 Fiddler Everywhere。
- 创建 PEM 证书。
- 为基于 Electron 的应用设置 Fiddler CA 证书。
- 在 Firefox 中设置 Fiddler CA 证书。
