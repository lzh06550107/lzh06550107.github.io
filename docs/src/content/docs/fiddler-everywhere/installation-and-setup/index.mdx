# 安装与设置

本节对应官方菜单 **Installation & Setup**。该菜单用于介绍在不同系统上安装、首次启动、信任 Fiddler CA 证书、离线模式、托管应用配置和高级安装方式。

## 菜单页面顺序

以下顺序按照官方文档仓库和菜单结构保留：

1. **Advanced Installation**：高级安装。
2. **Managed App Configuration**：托管应用配置。
3. **Offline Mode**：离线模式。
4. **First Steps on Linux**：Linux 上的初始步骤。
5. **First Steps on macOS**：macOS 上的初始步骤。
6. **First Steps on Windows**：Windows 上的初始步骤。
7. **Trust Fiddler CA**：信任 Fiddler CA 证书。

## 章节说明

安装与设置流程的核心是：先安装 Fiddler Everywhere，再根据系统完成初始配置；如果需要捕获 HTTPS 流量，还需要安装并信任 Fiddler 根证书。企业环境中，还可以通过策略驱动安装、托管应用配置和离线模式来满足集中部署、安全限制或无互联网环境下的使用需求。
