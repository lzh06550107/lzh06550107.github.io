# 欢迎使用 Fiddler Everywhere

Progress® Telerik® Fiddler Everywhere 是一款 Web 调试工具，可监控、检查、编辑和记录所有 HTTPS 流量，在你的计算机与互联网之间发出请求，并处理传入和传出的数据。

它是一款适用于任何浏览器、系统或平台的高性能、跨平台代理。

## 主要功能

Fiddler Everywhere 提供了一系列实用且用户友好的功能，其数量和后续发展并不受本节列表限制。Fiddler 团队持续投入精力来提升性能，为现有 Web 调试代理工具增加更多价值，并在其可用功能之上继续构建。

### 流量捕获

Fiddler Everywhere 捕获并记录你的计算机与互联网之间的所有 HTTPS、WebSocket、Server-Sent Events、gRPC 和 Socket.IO 流量，并允许你从几乎任何支持系统代理的应用程序中捕获流量。

[阅读更多关于使用 Fiddler Everywhere 捕获 HTTPS 流量的内容...](https://www.telerik.com/fiddler/fiddler-everywhere/documentation/capture-traffic/get-started)

### 独立浏览器捕获

Fiddler Everywhere 提供了一种用于自动、沙盒化浏览器 HTTPS 捕获的选项，无需修改操作系统代理。[阅读更多关于独立的 Fiddler Everywhere 浏览器抓包功能...](https://www.telerik.com/fiddler/fiddler-everywhere/documentation/capture-traffic/capture-browser-traffic)

### 终端捕获

Fiddler Everywhere 提供了一种用于自动、沙盒化终端 HTTPS 捕获的选项。[阅读更多关于 Fiddler 终端抓包的内容...](https://www.telerik.com/fiddler/fiddler-everywhere/documentation/capture-traffic/capturing-traffic-from-terminal)

### 流量分析

Fiddler Everywhere 提供 HTTPS 和 WebSocket 流量分析功能，它会以结构化方式呈现捕获的信息，并为一个或多个捕获会话可视化各种统计数据。你还可以解密安全流量，并保存、接收、比较以及与协作者共享捕获的流量。阅读更多关于使用 Fiddler Everywhere [检查](https://www.telerik.com/fiddler/fiddler-everywhere/documentation/inspect-traffic/inspect-traffic)和[修改](https://www.telerik.com/fiddler/fiddler-everywhere/documentation/modify-and-filter-traffic/modify-traffic-with-rules)流量的内容...

### 现代 HTTP 和 TLS 版本支持

Fiddler Everywhere 支持正在使用的 HTTP 协议版本，包括广泛使用的 HTTP/1.1 和最新的主要修订版 HTTP/2。Fiddler Everywhere 支持已过时和现代的 SSL 与 TLS 版本，包括 TLS 1.2 和 TLS 1.3。

[在此处了解更多关于启用 Fiddler Everywhere HTTP/2 抓包的信息...](https://www.telerik.com/fiddler/fiddler-everywhere/documentation/user-guide/settings/connections)

[在此处了解更多关于 TLS 支持的信息...](https://www.telerik.com/fiddler/fiddler-everywhere/documentation/security/tls-version-specifics)

### 高级协议支持

Fiddler Everywhere 为传统 HTTP/HTTPS 之外的现代 Web 协议和技术提供全面支持：

- **WebSocket**：用于实时应用程序的全双工通信协议。
- **Server-Sent Events（SSE）**：用于实时更新的服务器到客户端流式传输。
- **gRPC**：构建在 HTTP/2 之上的高性能 RPC 框架。
- **Socket.IO**：基于事件的实时双向通信。
- **Streaming HTTP**：用于连续数据流的长生命周期 HTTP 连接。

这种广泛的协议支持使开发者能够使用单一工具调试复杂的现代应用程序、微服务和实时系统。

[了解更多关于捕获和检查不同协议的内容...](https://www.telerik.com/fiddler/fiddler-everywhere/documentation/capture-traffic/capturing-modes)

### 请求和响应模拟

Fiddler 支持对所有 HTTP 请求和响应进行模拟、修改以及设置断点。借助 Fiddler 规则，你可以快速更改 HTTPS 请求和响应，而无需更新代码，也无需访问服务器或客户端应用程序。[阅读更多关于使用 Fiddler Everywhere 创建用于修改请求和响应的规则的内容...](https://www.telerik.com/fiddler/fiddler-everywhere/documentation/modify-and-filter-traffic/organizing-rules)

### API 编写

Fiddler Everywhere 随附一个 API Composer，它允许你通过创建和发送请求，以及保存和共享已编写的 API，来测试 REST 和 SOAP API。你可以在开发新 API 和测试现有 API 时使用 API 编写功能。

### 安全协作

Fiddler Everywhere 提供了一种安全方法，用于保存网络调试日志，并将其与你的团队共享，以便进行分析、沟通和解决问题。

### 跨平台支持

Fiddler Everywhere 提供与平台无关的兼容性，使你能够在 Windows、macOS 和 Linux 系统操作机器上安装、配置和运行该 Web 调试工具。

- [在 Windows 上开始使用 Fiddler Everywhere](./installation-and-setup/)
- [在 macOS 上开始使用 Fiddler Everywhere](./installation-and-setup/)
- [在 Linux 上开始使用 Fiddler Everywhere](./installation-and-setup/)

### 移动端上的 Fiddler Everywhere

Fiddler Everywhere 还允许你在运行 iOS 和 Android 的设备上捕获和检查流量。
