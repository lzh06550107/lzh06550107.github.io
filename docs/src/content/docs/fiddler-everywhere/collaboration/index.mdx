# 协作

本节对应官方菜单 **Collaboration**。它介绍如何保存、导入、导出和共享 Fiddler Everywhere 中捕获或整理的数据。

## 菜单页面顺序

1. **Exporting and Importing**：导出和导入。
2. **Saving Data**：保存数据。
3. **Sharing Data**：共享数据。

## 功能说明

Fiddler Everywhere 提供安全的方法保存和共享网络调试日志。团队成员可以基于相同的会话数据进行分析、沟通和问题解决。对于支持人员、测试人员和开发人员协同排查网络问题，这类能力尤其重要。
