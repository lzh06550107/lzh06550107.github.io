# 支持选项

Fiddler Everywhere 为其付费订阅用户和试用用户提供完整支持。它还维护额外的支持渠道，你可以在这些渠道中提问、提交功能请求、报告 bug 等。

## 付费订阅和试用用户支持

Fiddler 许可证持有者以及处于有效试用期内的任何用户，都可以获得由构建该工具的开发者提供的 Fiddler Everywhere 客户支持。使用 Fiddler Everywhere 应用程序内的 **Contact Support** 选项打开支持中心并提交支持工单。订阅计划包含对 Fiddler 专属支持服务的无限访问。

不过，为了持续提供行业领先的支持体验，官方对支持服务实施了公平使用政策。这意味着，如果客户活动至少超过平均水平十倍，Fiddler 支持经理可能随时审查该活动，以评估支持请求数量是否过多，以及用户是否违反公平使用政策。

面向付费订阅或试用用户的支持服务包括：

- **现有功能使用指导**：你将收到现有资源引用，这些资源展示产品预期用法，以及产品正确配置的信息。
- **确认 bug 报告**：你可以依靠支持团队来诊断并确认已报告的产品 bug。
- **共享可用解决方案**：如果存在可用方案，你会收到针对已确认产品 bug 或未作为内置功能实现的场景的建议解决办法。

## 免费支持渠道

如果你不是许可证持有者或试用用户，可以使用可用的支持选项：

- 使用 Fiddler Everywhere 应用程序内的 **Feedback** 选项访问 Fiddler Feedback 门户，在那里发布反馈、功能请求以及与 Fiddler Everywhere 应用相关的问题。
- 使用应用程序内的 **Report an Issue** 选项访问 Fiddler Everywhere 公共 GitHub 仓库，它是官方公开 bug 和功能请求跟踪器。
- Fiddler 讨论区也是你可以从社区和 Fiddler Everywhere 团队获得免费支持的地方。
- 官方 Fiddler Everywhere 文档是公开的，所有用户都可以访问。
