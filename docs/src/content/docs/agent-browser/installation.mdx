# 安装

## 全局安装（推荐）

安装原生 Rust 二进制文件以获得最佳性能：

```bash
npm install -g agent-browser
agent-browser install  # 首次从 Chrome for Testing 下载 Chrome
```

这是最快的方式：命令会直接通过原生 Rust CLI 运行，解析开销低于毫秒级。

## 快速开始（无需安装）

```bash
npx agent-browser install   # 仅首次下载 Chrome
npx agent-browser open example.com
```

## 项目安装（本地依赖）

适合希望在 `package.json` 中固定版本的项目：

```bash
npm install agent-browser
npx agent-browser install  # 首次下载 Chrome
```

之后可通过 `npx` 或 `package.json` scripts 使用。

## Homebrew（macOS）

```bash
brew install agent-browser
agent-browser install  # 首次下载 Chrome
```

## Cargo（Rust）

```bash
cargo install agent-browser
agent-browser install  # 首次下载 Chrome
```

从源码编译约需 2–3 分钟，需要 Node.js 24+、pnpm 11+ 和 Rust 工具链。

## 从源码安装

```bash
git clone https://github.com/vercel-labs/agent-browser
cd agent-browser
pnpm install
pnpm build
pnpm build:native
./bin/agent-browser install
pnpm link --global
```

## Linux 依赖

在 Linux 上安装系统依赖：

```bash
agent-browser install --with-deps
```

## 更新

升级到最新版本：

```bash
agent-browser upgrade
```

该命令会检测你的安装方式（npm、Homebrew 或 Cargo），并自动运行对应的更新命令。

## Doctor

`doctor` 用于诊断安装问题，并自动清理过期的守护进程文件：

```bash
agent-browser doctor
agent-browser doctor --offline --quick
agent-browser doctor --fix
agent-browser doctor --json
```

它会检查环境、Chrome、守护进程、配置、安全、Provider、网络以及启动测试。

## 自定义浏览器

你可以使用自定义浏览器可执行文件，而不是捆绑 Chromium：

```bash
agent-browser --executable-path /path/to/chromium open example.com

AGENT_BROWSER_EXECUTABLE_PATH=/path/to/chromium agent-browser open example.com
```

## AI Agent 设置

安装适用于 AI 编码助手的 skill：

```bash
npx skills add vercel-labs/agent-browser
```

适用于 Claude Code、Codex、Cursor、Gemini CLI、GitHub Copilot、Goose、OpenCode 和 Windsurf。

:::caution
不要直接复制 `node_modules` 里的 `SKILL.md`，否则随着新功能发布会过期。请使用 `npx skills add` 或引用仓库版本。
:::

## Browser Automation

Use `agent-browser` for web automation. Run `agent-browser --help` for all commands.

Core workflow:
1. `agent-browser open <url>` - Navigate to page
2. `agent-browser snapshot -i` - Get interactive elements with refs (@e1, @e2)
3. `agent-browser click @e1` / `fill @e2 "text"` - Interact using refs
4. Re-snapshot after page changes
