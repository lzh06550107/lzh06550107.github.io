# Browser Use

Browser Use 为 AI Agent 提供云浏览器基础设施，适合 serverless、CI/CD 等无法使用本地浏览器的环境。

## 设置

```bash
export BROWSER_USE_API_KEY="your-api-key"
agent-browser -p browseruse open https://example.com
```

或：

```bash
export AGENT_BROWSER_PROVIDER=browseruse
export BROWSER_USE_API_KEY="your-api-key"
agent-browser open https://example.com
```

`-p` flag 优先于 `AGENT_BROWSER_PROVIDER`。

启用后，agent-browser 会连接到 Browser Use 云会话，而不是启动本地浏览器。
